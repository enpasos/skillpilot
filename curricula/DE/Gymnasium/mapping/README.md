# DE Gymnasium Mapping Archive

This directory holds state-scoped legacy-to-canonical mapping files that must survive even after the source landscapes move toward `compatibility-only` or later deletion.

Conventions:

- keep mappings separated by jurisdiction, for example `DE-HE` and `DE-BY`
- keep school-stage splits explicit where operationally useful, for example `upper-secondary` and `lower-secondary`
- treat this directory as the long-lived audit/migration anchor for mapping fixtures
- do not require mappings to remain physically inside legacy source trees once they are stable enough to be shared here

Current active lanes:

- `DE-HE/upper-secondary`
- `DE-HE/lower-secondary`

Planned later lanes:

- `DE-BY/gymnasium`
