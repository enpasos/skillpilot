Zusatzanweisung:
Pflichtinhalt:
- Thema: Graphen von Integrand und Integralfunktion wechselseitig deuten.
- Verwende eine zweigeteilte Darstellung:
  oben der Integrand f(x), unten die Integralfunktion F(x) mit F'(x)=f(x).
- Nutze ein einfaches qualitatives Beispiel:
  f(x) ist positiv auf 0 < x < 2,
  f(x)=0 bei x=2,
  f(x) ist negativ auf 2 < x < 4.
- Daraus muss sichtbar folgen:
  F steigt auf 0 < x < 2,
  F hat bei x=2 einen Hochpunkt,
  F faellt auf 2 < x < 4.
- Zeige zusaetzlich kleine Pfeile/Labels:
  f > 0 -> F steigt.
  f = 0 -> waagrechte Tangente an F.
  f < 0 -> F faellt.
- Umgekehrte Deutung:
  Aus der Steigung von F liest man f ab.

Vermeiden:
- Nicht aus f>0 einen fallenden F-Graphen zeichnen.
- Nicht bei x=2 einen Tiefpunkt von F zeigen; hier ist es ein Hochpunkt.
- Nicht f und F als denselben Graphen darstellen.
- Keine falsche Aussage wie F(x)=f(x).
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
