## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Explizit definierte Folgen darstellen und berechnen (LK)
Beschreibung: Die lernende Person kann Folgenglieder explizit definierter Folgen berechnen und die Darstellung fachsprachlich deuten.

Zusatzanweisung:
Pflichtinhalt:

Show one explicit sequence only: `a_n = 2n + 1` for `n = 1, 2, 3, 4, 5`.
Use a clean table with exactly these rows: `n: 1, 2, 3, 4, 5` and `a_n: 3, 5, 7, 9, 11`.
Optionally show the matching discrete points `(1|3)`, `(2|5)`, `(3|7)`, `(4|9)`, `(5|11)` as separate dots, not as a continuous line.
Keep the idea focused on explicit calculation: insert `n`, compute `a_n`.

Vermeiden:

Do not show wrong indexing such as `a_0 = 3` for this example.
Do not connect the sequence points with a continuous function graph.
Avoid arrows. If any arrow is used, its source and target must be mathematically exact.
Do not add recursive formulas, limits, convergence, or unrelated sequence types.
```
