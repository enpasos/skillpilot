```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.

Titel: Periodische Prozesse modellieren
Beschreibung: Die lernende Person kann periodische Realsituationen (z. B. Gezeiten, Schwingungen) mit Sinus- oder Kosinusfunktionen beschreiben, Parameter mithilfe von Messdaten bestimmen und Aussagen zum Verlauf treffen.

Zusatzanweisung:
Pflichtinhalt:

- Show a periodic real-world process as measured data points and a fitted sine curve.
- Use a simple tide-like setting with axes `Zeit in h` and `Wasserstand in m`.
- Mark the model parameters visually:
  - midline `d`;
  - amplitude as a vertical arrow from the midline to a crest;
  - period as a horizontal arrow from one crest to the next crest.
- Add a compact model template `f(t)=a sin(b(t-c))+d` next to the graph.
- Include a small note that predictions are only reasonable for a limited time range.

Vermeiden:

- Do not draw the amplitude arrow horizontally; amplitude is vertical.
- Do not draw the period arrow vertically; period is horizontal along the time axis.
- Do not make the data points perfectly identical to the curve at every point; a few slight deviations are fine.
- Do not include technical IDs, filenames, watermarks, or brand names.
```
