Pflichtinhalt:
- Show exactly one coordinate system with the graph y = sqrt(x), only for x >= 0.

- If using an arrow for "Startpunkt (0|0)", the arrow tip must end at the origin where x-axis and y-axis meet, not somewhere on the x-axis to the right and not below the graph.

- Include the short properties "steigend" and "wird flacher".

Vermeiden:
- Do not place the "Startpunkt (0|0)" arrow anywhere except on the origin.
- Do not point "Startpunkt (0|0)" to a later point on the x-axis.
- Do not draw values for negative x.
- Do not draw a parabola or a straight line.
- Do not use hollow marker style if it makes (0|0) look excluded.
- Do not add technical identifiers or watermarks.
