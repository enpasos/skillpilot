Zusatzanweisung:
Pflichtinhalt:
- Thema: Schnittpunkte mehrerer Geraden mit einer Ebene berechnen.
- Verwende eine gemeinsame Ebene:
  E: x + y + z = 5.
- Gerade g:
  g: X=(1; 1; 1)+t*(1; 0; 1).
  Einsetzen: (1+t)+1+(1+t)=5 -> 3+2t=5 -> t=1.
  Schnittpunkt S_g=(2;1;2).
- Gerade h:
  h: X=(0; 2; 0)+s*(2; 0; 1).
  Einsetzen: 2s+2+s=5 -> 2+3s=5 -> s=1.
  Schnittpunkt S_h=(2;2;1).
- Zeige eine 3D-Skizze mit Ebene E und zwei verschieden gefaerbten Geraden g und h, jede mit ihrem Schnittpunkt.
- Deutung:
  Jede Gerade wird durch Einsetzen ihrer Parameterdarstellung auf eine lineare Gleichung im Parameter reduziert.

Vermeiden:
- Die beiden Schnittpunkte nicht vertauschen.
- Nicht fuer beide Geraden denselben Parameterbuchstaben verwenden, wenn es die Darstellung unklar macht.
- Nicht behaupten, es gebe immer genau einen Schnittpunkt; hier schneiden beide Beispielgeraden die Ebene.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
