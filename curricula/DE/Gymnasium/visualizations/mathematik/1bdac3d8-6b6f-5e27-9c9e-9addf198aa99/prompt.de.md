## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Parameterbereiche für Lösungsexistenz analysieren (LK)
Beschreibung: Die lernende Person kann für eine Funktionenschar begründen, für welche Parameterbereiche eine geforderte Lösung existiert.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Parameterbereich fuer die Existenz reeller Loesungen.
- Verwende genau diese Gleichung: x^2 = a.
- Zeige die gleichwertige Funktionenschar: f_a(x) = x^2 - a.
- Visualisiere mit der Parabel y = x^2 und horizontalen Geraden y = a.
- Drei Faelle:
  a > 0 -> zwei reelle Loesungen x = -sqrt(a) und x = sqrt(a).
  a = 0 -> eine doppelte Loesung x = 0.
  a < 0 -> keine reelle Loesung.
- Ergebnisbox: Reelle Loesung existiert genau fuer a >= 0.

Vermeiden:
- Keine komplexen Loesungen anzeigen.
- Kein falscher Bereich wie a > 0 allein.
- Nicht behaupten, dass a<0 zwei Loesungen hat.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
