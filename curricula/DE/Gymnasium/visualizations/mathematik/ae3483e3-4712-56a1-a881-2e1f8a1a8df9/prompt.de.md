Zusatzanweisung:
Pflichtinhalt:
- Thema: Stichprobenumfang aus einem Guetefunktionsgraphen ablesen.
- Zeige einen klaren Graphen einer Guetefunktion G(n) fuer eine feste Alternative.
- x-Achse: Stichprobenumfang n.
- y-Achse: Guete G(n).
- Verwende genau diese Stuetzpunkte und eine ruhig ansteigende Kurve:
  (20|0.55), (40|0.72), (60|0.85), (80|0.93).
- Zeichne eine horizontale Mindestlinie bei G(n)=0.80.
- Markiere den ersten gezeigten Stichprobenumfang, der die Mindestlinie erreicht oder ueberschreitet:
  n=60, denn G(60)=0.85 >= 0.80.
- Ergebnisbox: Mindestguete 0.80 -> waehle n >= 60; kleinster gezeigter passender Stichprobenumfang: n=60.

Vermeiden:
- Nicht die y-Achse als Fehlerwahrscheinlichkeit oder Ablehnungswahrscheinlichkeit falsch beschriften.
- Keine fallende Kurve.
- Keine falsche Markierung bei n=40; dort gilt nur G(40)=0.72 < 0.80.
- Keine erfundenen Testparameter, keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
