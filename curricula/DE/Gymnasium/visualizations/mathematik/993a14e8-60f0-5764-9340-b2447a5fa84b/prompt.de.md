```text
Titel: Parameter in Funktionenscharen deuten
Beschreibung: Die lernende Person kann den Parameter einer Funktionenschar als veränderliche Größe deuten und seinen Einfluss auf eine ausgewählte Grapheneigenschaft qualitativ erklären.

Zusatzanweisung:
Required content:

- Show a simple function family `f_a(x) = x^2 + a`.
- Explain `a` as a variable parameter, not as the input variable.
- Show three small graph sketches or cards:
  - `a = -1`: parabola shifted 1 unit down, vertex `S(0|-1)`
  - `a = 0`: base parabola, vertex `S(0|0)`
  - `a = 2`: parabola shifted 2 units up, vertex `S(0|2)`
- Use one short German interpretation: `a veraendert die Lage des Graphen, nicht die Oeffnung`.
- Clearly distinguish `x` as input and `a` as parameter.

Avoid:

- Do not show a horizontal shift for `x^2 + a`.
- Do not change the parabola width or opening direction for this example.
- Do not use more than one function family in the same image.
- Do not include technical IDs, filenames, watermarks, platform names, or product names.
```
