## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Schrägbilder räumlicher Objekte zeichnen
Beschreibung: Die lernende Person kann geeignete Schrägbilder räumlicher Objekte zeichnen und die Darstellung fachsprachlich erläutern.

Zusatzanweisung:
Pflichtinhalt:

Show how to draw an oblique sketch (`Schrägbild`) of a cuboid.
Use exactly this example:
- real cuboid dimensions: width `4 cm`, height `3 cm`, depth `2 cm`
- front rectangle drawn in true size: `4 cm x 3 cm`
- receding depth edges drawn at `45°`
- receding depth shortened by half: `2 cm real -> 1 cm in the sketch`
- back rectangle parallel to the front rectangle

Use a simple construction layout:
1. front rectangle `4 cm x 3 cm`
2. slanted depth edges at `45°`, length `1 cm`
3. connect corresponding back vertices

If a reference image is provided, preserve its proportions exactly: front width : height is `4 : 3`, and each drawn depth edge is exactly one quarter of the front width. Keep the back rectangle parallel to the front rectangle.

Vermeiden:

Do not use a 3D perspective vanishing point; this is an oblique drawing, not central perspective.
Do not draw the receding edges full length `2 cm`.
Do not draw depth edges longer than one quarter of the 4 cm front width.
Do not make the back rectangle non-parallel to the front rectangle.
Do not use decorative arrows. Use labels next to edges, not arrow-heavy annotations.
Do not add volume or surface-area formulas.
```
