Titel: Dichtheit der rationalen Zahlen erläutern
Beschreibung: Die lernende Person kann erläutern, dass zwischen zwei verschiedenen rationalen Zahlen stets beliebig viele weitere rationale Zahlen liegen, und Beispiele dafür angeben.

Zusatzanweisung:
Do not include any technical IDs, filenames, database IDs, project names, watermarks, logos, or QR codes. Keep all visible German text short and correctly spelled. Use a simple clean teaching graphic with only these five fractions anywhere in the image: 1/2, 9/16, 5/8, 11/16, 3/4. No other fractions, no tiny decorative math, no fraction clouds, no background formulas. Show them in this left-to-right order on one number line: 1/2, 9/16, 5/8, 11/16, 3/4. Explain: Zwischen zwei rationalen Zahlen liegt wieder eine rationale Zahl. Show 5/8 as midpoint between 1/2 and 3/4. State: Es gibt keine nächste rationale Zahl.
