Beschreibung: Die lernende Person kann Parameterwerte berechnen, für die eine Scharfunktion eine vorgegebene Nullstelle besitzt, und die Lösung algebraisch begründen.

Zusatzanweisung:
Required content:

- Show a clear algebra example for choosing a parameter so a given zero occurs.
- Use exactly this function family: `f_a(x) = x^2 + a`.
- Given zero: `x = 2`.
- Show the condition `f_a(2) = 0`.
- Compute `2^2 + a = 0`, hence `4 + a = 0`, so `a = -4`.
- Show the check: `f_-4(x) = x^2 - 4`, and `f_-4(2) = 0`.
- Optionally show the graph crossing the x-axis at `x = -2` and `x = 2`, but highlight the required zero `x = 2`.

Avoid:

- Do not solve for `x`; the unknown in this task is the parameter `a`.
- Do not forget the second zero `x=-2` if the graph is shown.
- Do not claim `a=4`.
- Do not include technical IDs, filenames, watermarks, platform names, or product names.
