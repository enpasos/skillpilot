```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:

Titel: Gleichungen mit dem Satz vom Nullprodukt lösen
Beschreibung: Die lernende Person kann faktorisierte Gleichungen mit dem Satz vom Nullprodukt lösen und die Lösungen durch Einsetzen prüfen.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Faktorisierte Gleichung mit dem Satz vom Nullprodukt loesen.
- Verwende die Gleichung:
  (x - 2) * (x + 3) = 0.
- Zeige den Satz:
  Ein Produkt ist genau dann 0, wenn mindestens ein Faktor 0 ist.
- Loesungsweg:
  x - 2 = 0  ->  x = 2.
  x + 3 = 0  ->  x = -3.
- Loesungsmenge:
  L = {-3, 2}.
- Pruefung durch Einsetzen:
  x=2: (2-2)*(2+3)=0*5=0.
  x=-3: (-3-2)*(-3+3)=(-5)*0=0.
- Visualisiere die zwei Faktoren als zwei getrennte Entscheidungskaesten.

Vermeiden:
- Nicht ausmultiplizieren als Hauptmethode; Ziel ist der Satz vom Nullprodukt.
- Nicht nur x=2 angeben; beide Loesungen gehoeren dazu.
- x=-3 nicht als x=3 schreiben.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
