Pflichtinhalt:
- Thema: Projektionen auf Koordinatenebenen untersuchen.
- Zeige den Punkt P(3|-2|4) in einem 3D-Koordinatensystem.
- Zeige die drei senkrechten Projektionen:
  auf die xy-Ebene: P_xy = (3|-2|0), z wird 0.
  auf die xz-Ebene: P_xz = (3|0|4), y wird 0.
  auf die yz-Ebene: P_yz = (0|-2|4), x wird 0.
- Zeige daneben eine kleine Dreiecksprojektion auf die xy-Ebene:
  A(1|1|3) -> A'(1|1|0),
  B(4|1|3) -> B'(4|1|0),
  C(2|3|5) -> C'(2|3|0).
- Deutung: Projektion auf eine Koordinatenebene setzt die senkrechte Koordinate auf 0 und erhaelt die beiden Koordinaten in der Ebene.

Vermeiden:
- Die Projektionsregeln nicht vertauschen.
- Bei P_xy nicht x oder y auf 0 setzen; nur z wird 0.
- Bei P_xz nicht z auf 0 setzen; nur y wird 0.
- Bei P_yz nicht y oder z auf 0 setzen; nur x wird 0.
