## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Nenner mit Wurzeltermen rationalisieren
Beschreibung: Die lernende Person kann einfache Wurzelterme so umformen, dass Nenner rational werden, und die Äquivalenz der Umformung begründen.

Zusatzanweisung:
Erzeuge genau eine fokussierte Infografik zum Rationalisieren einfacher Nenner mit Wurzeltermen.

Pflichtinhalt:
- Drei klar getrennte Mini-Panels.
- Panel 1: Problem sichtbar machen: `3/√2` hat eine Wurzel im Nenner.
- Panel 2: Mit `1` erweitern: `3/√2 · √2/√2 = 3√2/2`.
- Panel 3: Zweites Beispiel: `5/(2√3) · √3/√3 = 5√3/6`.
- Eine kleine Begründung: Wert bleibt gleich, weil mit `√b/√b = 1` erweitert wird; Nenner wird rational.

Vermeiden:
- Keine binomischen Nenner oder Konjugierten.
- Keine teilweise Radizierung als eigenes Thema.
- Keine Potenzen von Wurzeltermen.
- Keine Wahrscheinlichkeit, keine Heron-Näherung, kein Irrationalitätsbeweis.
- Keine dekorativen Nebenformeln.

Layout:
- Einfacher Cartoon-Tafelstil, wenig Text, große lesbare Brüche, keine Wasserzeichen.
```
