Beschreibung: Die lernende Person kann simultane Kongruenzen unter Bezug auf den chinesischen Restsatz lösen.

Zusatzanweisung:
Pflichtinhalt:

Solve exactly this CRT system:
`x ≡ 2 mod 3`
`x ≡ 3 mod 5`
State that `3` and `5` are coprime, so the solution is unique modulo `15`.
Show candidates from the first congruence: `2, 5, 8, 11, 14`.
Check modulo `5`: only `8 ≡ 3 mod 5`.
Final result: `x ≡ 8 mod 15`.

Vermeiden:

Do not give `x = 3`, `x = 5`, or `x ≡ 2 mod 15` as the final answer.
Do not use non-coprime moduli.
Use no arrows; use two small residue columns or a table.
Do not add a second unrelated CRT example.
