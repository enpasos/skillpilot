```text
Titel: Punktprobe und Lage eines Punktes zur Ebene prüfen
Beschreibung: Die lernende Person kann eine Punktprobe durchführen und die Lage eines Punktes zur Ebene (auf, parallel, nicht auf) bestimmen.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Punktprobe und Lage eines Punktes zu einer Ebene pruefen.
- Verwende die Ebene:
  E: x - 2y + z = 4.
- Punktprobe fuer A:
  A=(4; 0; 0).
  4 - 0 + 0 = 4, also A liegt auf E.
- Punktprobe fuer B:
  B=(1; 0; 0).
  1 - 0 + 0 = 1 ungleich 4, also B liegt nicht auf E.
- Signed residual fuer B:
  x - 2y + z - 4 = -3.
- Zeige eine 3D-Skizze mit Ebene E, A direkt auf der Ebene und B sichtbar ausserhalb der Ebene.
- Zeichne optional eine gestrichelte Lotrichtung parallel zu n=(1; -2; 1) von B zur Ebene, ohne einen falschen Fusspunkt zu beschriften.
- Deutung:
  Punktprobe bedeutet: Koordinaten einsetzen und linke Seite mit rechter Seite vergleichen.
  Ein einzelner Punkt ist nicht "parallel" zu einer Ebene; er liegt auf der Ebene oder nicht auf der Ebene.

Vermeiden:
- B nicht als Punkt auf der Ebene markieren.
- Keine Aussage "Punkt B ist parallel zur Ebene" schreiben.
- Nicht 1=4 als wahr darstellen.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
