```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Titel: Geometrische Reihen in Anwendungen nutzen (LK)
Beschreibung: Die lernende Person kann geometrische Reihen in geeigneten Anwendungssituationen modellieren und auswerten.

Zusatzanweisung:
Pflichtinhalt:

Use a simple application with repeated halving of echo intensity.
Scenario: first echo has intensity `80`, each following echo has half the previous intensity.
Show the geometric series `80 + 40 + 20 + 10 + ...`.
Show `a = 80`, `q = 1/2`, and `S = 80 / (1 - 1/2) = 160`.
Use a small table with echo number `1, 2, 3, 4` and intensities `80, 40, 20, 10`.
State the interpretation: total modeled echo intensity approaches `160`.

Vermeiden:

Do not use physical units that make the model look like an exact measurement law.
Do not draw wave arrows or direction arrows.
Do not change the ratio from `1/2`.
Do not show the finite partial sum `150` as the infinite total.
```
