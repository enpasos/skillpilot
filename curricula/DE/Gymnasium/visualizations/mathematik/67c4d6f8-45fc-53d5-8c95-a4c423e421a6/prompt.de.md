Beschreibung: Die lernende Person kann arithmetische und geometrische Folgen definieren, Terme für das n-te Glied aufstellen und Folgenwerte tabellarisch sowie grafisch darstellen.

Zusatzanweisung:
Pflichtinhalt:

- Show a side-by-side comparison of an arithmetic sequence and a geometric sequence.
- Arithmetic example:
  - table `n: 1,2,3,4`;
  - values `a_n: 5,8,11,14`;
  - rule `a_n = 5 + (n-1)*3`;
  - mark the constant difference `+3`.
- Geometric example:
  - table `n: 1,2,3,4`;
  - values `b_n: 2,4,8,16`;
  - rule `b_n = 2*2^(n-1)`;
  - mark the constant factor `*2`.
- Include a small dot plot for both sequences with discrete points, not connected continuous curves.

Vermeiden:

- Do not connect sequence points with a smooth function curve.
- Do not mix up arithmetic difference and geometric factor.
- Do not change the values or formulas listed above.
- Do not include technical IDs, filenames, watermarks, or brand names.
