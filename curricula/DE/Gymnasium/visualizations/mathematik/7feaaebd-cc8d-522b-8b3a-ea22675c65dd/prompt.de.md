```text
Titel: Extremstellen parameterabhängig untersuchen
Beschreibung: Die lernende Person kann Ableitungen verwenden, um Extremstellen einer Funktionenschar in Abhängigkeit vom Parameter zu bestimmen und die Ergebnisse zu prüfen.

Zusatzanweisung:
Required content:

- Show a derivative-based parameter example for extrema.
- Use exactly this function family: `f_a(x) = x^2 - 2*a*x`.
- Compute the derivative: `f'_a(x) = 2x - 2a`.
- Set `f'_a(x)=0`, giving `x = a`.
- Use `f''_a(x)=2 > 0`, so the extremum is a minimum.
- State the point: `T_a = (a | -a^2)`.
- Show a small table:
  - `a = -1` gives `T(-1|-1)`
  - `a = 0` gives `T(0|0)`
  - `a = 2` gives `T(2|-4)`

Avoid:

- Do not mark the extremum as a maximum.
- Do not write `x=-a` for this function family.
- Do not omit the second-derivative or shape check.
- Do not include technical IDs, filenames, watermarks, platform names, or product names.
```
