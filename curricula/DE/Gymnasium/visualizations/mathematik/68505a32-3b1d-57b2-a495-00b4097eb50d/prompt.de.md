## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Potenzen von Wurzeltermen vereinfachen
Beschreibung: Die lernende Person kann Potenzen von Wurzeltermen zielgerichtet vereinfachen und die verwendeten Potenz- und Wurzelgesetze begründen.

Zusatzanweisung:
Erzeuge genau eine fokussierte Infografik zu Potenzen von Wurzeltermen.

Pflichtinhalt:
- Drei klar getrennte Mini-Panels.
- Panel 1: `(√5)^2 = 5` mit kurzer Idee: Quadrieren hebt das Wurzelziehen auf.
- Panel 2: `(2√3)^2 = 2^2 · (√3)^2 = 4 · 3 = 12`.
- Panel 3: Allgemein: `(√a)^2 = a` für `a ≥ 0` und `(k√a)^2 = k^2a` für `a ≥ 0`.
- Eine kleine Warnung: Den Faktor vor der Wurzel immer mitquadrieren.

Vermeiden:
- Keine teilweise Radizierung wie `√72 = 6√2`.
- Kein Nenner-Rationalisieren.
- Keine Wahrscheinlichkeit, keine Heron-Näherung, kein Irrationalitätsbeweis.
- Keine Addition oder Subtraktion von Wurzeltermen.
- Keine dekorativen Nebenformeln.

Layout:
- Einfacher Cartoon-Tafelstil, wenig Text, große lesbare Formeln, keine Wasserzeichen.
```
