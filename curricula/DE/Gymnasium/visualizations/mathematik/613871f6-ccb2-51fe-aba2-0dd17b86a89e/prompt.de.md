```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:

- Erzeuge eine klare, gut lesbare Infografik im Querformat.

- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.

Titel: Entscheidungsregel für eine komplexe Problemstellung entwickeln (LK)
Beschreibung: Die lernende Person kann für eine komplexere Problemstellung eine mathematisch begründete Entscheidungsregel formulieren.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Eine mathematisch begruendete Entscheidungsregel formulieren.
- Kontext: Zwei Stromtarife fuer x kWh Verbrauch pro Monat.
- Tarif A: A(x) = 12 + 0.32x.
- Tarif B: B(x) = 24 + 0.24x.
- Zeige den Schnittpunkt:
  12 + 0.32x = 24 + 0.24x
  0.08x = 12
  x = 150
- Zeige die Entscheidungsregel als Fallunterscheidung:
  Fuer x < 150: Tarif A ist guenstiger.
  Fuer x = 150: beide Tarife kosten gleich viel.
  Fuer x > 150: Tarif B ist guenstiger.
- Optional: Diagramm mit zwei Geraden und markiertem Schnittpunkt S(150 | 60), denn A(150)=B(150)=60.

Vermeiden:
- Keine falsche Ungleichungsrichtung.
- Keinen falschen Schnittpunkt.
- Nicht die Grundpreise oder kWh-Preise vertauschen.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
