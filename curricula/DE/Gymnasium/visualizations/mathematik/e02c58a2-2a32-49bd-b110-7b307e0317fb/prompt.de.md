## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Funktionsbegriff und Darstellungen verstehen
Beschreibung: Die lernende Person kann Funktionen als Zuordnungen beschreiben, abhängige und unabhängige Größen unterscheiden und einfache Funktionsdarstellungen in Tabelle, Graph und Term deuten.

Zusatzanweisung:
Do not include any technical IDs, platform names, UUIDs, file names, database identifiers, watermarks, signatures, or hidden labels anywhere in the image. Explain function concept using one simple context: notebooks cost 2 EUR each. Independent variable x = number of notebooks, dependent variable y = price in EUR. Show term y = 2x. Show table x: 0,1,2,3 and y: 0,2,4,6. Show a coordinate graph with points (0,0), (1,2), (2,4), (3,6) on a straight rising line. Add short labels: x wird gewaehlt, y haengt davon ab, ein x -> genau ein y. Keep all values consistent.
```
