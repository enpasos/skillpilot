```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Titel: Sachzusammenhänge mit Extremstellen modellieren
Beschreibung: Die lernende Person kann Sachzusammenhänge mit Extremstellen durch geeignete ganzrationale Funktionen modellieren und die Bedingungen fachlich deuten.

Zusatzanweisung:
Pflichtinhalt:

Show modeling with an extremum in a real-world context.
Use exactly this example:
- context: height of a water fountain jet
- model: `h(t) = -0.5*(t - 4)^2 + 8`
- maximum point: `H(4|8)`
- derivative check: `h'(t) = -(t - 4)`, so `h'(4) = 0`
- second derivative: `h''(t) = -1 < 0`, so the extremum is a maximum

Use a downward-opening parabola and a compact condition table:
`h(4)=8`, `h'(4)=0`, `h''(4)<0`, interpretation: maximum height is `8 m` at `t=4 s`.

Vermeiden:

Do not show a minimum.
Do not use an upward-opening parabola.
Do not move the vertex away from `(4|8)`.
Do not write `h''(t)>0`.
Do not add arrows unless they are coordinate-axis arrowheads.
Do not add physical units that contradict `t` in seconds and `h` in meters.
```
