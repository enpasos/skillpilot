```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Titel: Schnittpunkt von Gerade und Ebene berechnen
Beschreibung: Die lernende Person kann den Schnittpunkt einer Geraden mit einer Ebene über ein lineares Gleichungssystem bestimmen und geometrisch interpretieren.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Schnittpunkt einer Geraden mit einer Ebene berechnen.
- Verwende:
  Ebene E: x + y + z = 5.
  Gerade g: X=(1; 2; 0)+t*(1; 0; 1).
- Einsetzen in E:
  x=1+t, y=2, z=t.
  (1+t)+2+t=5.
  3+2t=5.
  t=1.
- Schnittpunkt:
  S=(1;2;0)+1*(1;0;1)=(2;2;1).
- Zeige eine klare 3D-Skizze mit Ebene E, Gerade g, und markiertem Schnittpunkt S auf beiden Objekten.
- Deutung:
  Der Parameterwert t=1 liefert den gemeinsamen Punkt von Gerade und Ebene.

Vermeiden:
- Nicht t=2 oder t=0 schreiben.
- Nicht S=(2;2;0) oder S=(1;2;1) schreiben.
- Die Gerade darf nicht parallel zur Ebene aussehen; sie muss die Ebene schneiden.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
