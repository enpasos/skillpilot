```text
Titel: Zwischen Ebenenformen umformen
Beschreibung: Die lernende Person kann Parameterform, Punkt-Normalen-Form und Koordinatenform einer Ebene ineinander überführen.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Parameterform, Punkt-Normalen-Form und Koordinatenform einer Ebene ineinander ueberfuehren.
- Start in Parameterform:
  E: X=(1; 0; 2) + s*(2; 1; 0) + t*(0; 1; 1), s,t in R.
- Richtungsvektoren:
  u=(2;1;0), v=(0;1;1).
- Normalenvektor ueber Kreuzprodukt:
  n = u x v = (1; -2; 2).
- Punkt-Normalen-Form:
  ((x; y; z) - (1; 0; 2)) * (1; -2; 2) = 0.
- Koordinatenform:
  (x-1) - 2y + 2(z-2) = 0.
  x - 2y + 2z = 5.
- Zeige eine Prozessgrafik mit drei verbundenen Kaesten:
  Parameterform -> Punkt-Normalen-Form -> Koordinatenform.
- Zeige daneben eine kleine 3D-Skizze der Ebene mit u und v in der Ebene sowie n senkrecht dazu.

Vermeiden:
- Kreuzprodukt nicht als (-1;2;-2) verwenden, ausser dann auch die gesamte Gleichung konsistent gleichwertig bleibt; bevorzugt ist n=(1;-2;2).
- Nicht x - 2y + 2z = 0 schreiben; rechte Seite ist 5.
- u und v nicht parallel zeichnen.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
