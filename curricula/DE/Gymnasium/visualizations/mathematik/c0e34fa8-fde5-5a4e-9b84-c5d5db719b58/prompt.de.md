```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.

- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Mathematische Probleme erkennen und formulieren
Beschreibung: Die lernende Person kann alltagsnahe oder mathematische Fragestellungen in eine präzise mathematische Problemsituation überführen, Annahmen explizit machen und Zielgrößen festlegen.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Aus einer alltagsnahen Frage eine praezise mathematische Problemsituation formulieren.
- Kontext: Klassenfahrt mit Bus und Museum.
- Rohfrage oben links: "Was kostet die Klassenfahrt pro Person?"
- Mache die mathematische Praezisierung sichtbar:
  - Variable: n = Anzahl der teilnehmenden Personen.
  - Feste Buskosten: 420 Euro.
  - Eintritt: 6 Euro pro Person.
  - Zielgroesse: Preis pro Person p(n).
  - Annahme: Die Buskosten werden gleichmaessig auf alle Teilnehmenden verteilt.
- Zeige das Modell:
  K(n) = 420 + 6n
  p(n) = K(n) / n = (420 + 6n) / n
- Zeige eine Beispiel-Einsetzung fuer n = 28:
  p(28) = (420 + 168) / 28 = 588 / 28 = 21 Euro.
- Kernaussage: Problem erkennen heisst Variablen, Annahmen und Zielgroesse festlegen.

Vermeiden:
- Keine anderen Zahlenwerte verwenden.
- Keine unklare Formel ohne Variablendefinition.
- Keine falsche Division der Buskosten.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
