Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Titel: Zuordnungen analysieren
Beschreibung: Die lernende Person kann Zuordnungstabellen erstellen, grafisch darstellen und einfache funktionale Zusammenhänge deuten.

Zusatzanweisung:
Do not include any technical identifiers in the image. Create a German educational infographic about analyzing mappings / Zuordnungen. Use one simple context: Fahrradverleih with Grundgebuehr 2 EUR plus 3 EUR pro Stunde. Show a table: Stunden x = 0,1,2,3 and Kosten y = 2,5,8,11. Show the matching coordinate graph with points (0|2), (1|5), (2|8), (3|11) and a rising straight line. Add labels "Tabelle", "Graph", "Regel: y = 3x + 2", "deuten: Startgebuehr + Preis pro Stunde". Avoid calling it proportional, because it does not pass through the origin.
