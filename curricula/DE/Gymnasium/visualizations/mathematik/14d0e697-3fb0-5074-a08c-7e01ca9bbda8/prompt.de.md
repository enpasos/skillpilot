Zusatzanweisung:
Pflichtinhalt:
- Thema: Wurzelgleichungen durch einmaliges Quadrieren loesen.
- Verwende genau dieses Beispiel:
  sqrt(x + 5) = x - 1.
- Schritt 1:
  Definitions-/Vorzeichenbedingung fuer die rechte Seite: x - 1 >= 0, also x >= 1.
- Schritt 2:
  Einmal quadrieren:
  x + 5 = (x - 1)^2.
  x + 5 = x^2 - 2x + 1.
  0 = x^2 - 3x - 4.
  0 = (x - 4)(x + 1).
- Schritt 3:
  Kandidaten x = 4 und x = -1.
- Schritt 4:
  Probe in der Ausgangsgleichung:
  x = 4: sqrt(9) = 3 und 4 - 1 = 3, also echte Loesung.
  x = -1: sqrt(4) = 2, aber -1 - 1 = -2, also Scheinloesung.
- Ergebnis:
  L = {4}.

Vermeiden:
- Nicht beide Kandidaten als Loesungen akzeptieren.
- Die Probe nicht weglassen; Quadrieren kann Scheinloesungen erzeugen.
- Nicht sqrt(x + 5) = x - 1 direkt zu x + 5 = x - 1 machen.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
