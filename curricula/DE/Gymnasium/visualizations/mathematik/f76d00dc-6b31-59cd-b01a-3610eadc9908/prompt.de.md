```text
Titel: Monotoniesatz erläutern und Nichtumkehrbarkeit begründen
Beschreibung: Die lernende Person kann den Monotoniesatz für Ableitungen erläutern, ihn zur Monotonieuntersuchung nutzen und begründen, warum die Umkehrung im Allgemeinen nicht gilt.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Monotoniesatz erlaeutern und Nichtumkehrbarkeit begruenden.
- Zeige links den Monotoniesatz:
  Wenn f'(x) > 0 auf einem Intervall, dann ist f dort streng monoton steigend.
  Wenn f'(x) < 0 auf einem Intervall, dann ist f dort streng monoton fallend.
- Zeige rechts ein Gegenbeispiel zur Umkehrung:
  f(x) = x^3.
  f'(x) = 3x^2.
  f ist streng monoton steigend auf R.
  Aber f'(0) = 0.
- Kernaussage:
  Streng steigend bedeutet nicht automatisch f'(x) > 0 fuer alle x.
- Visualisierung:
  Graph von f(x)=x^3 steigt durch den Ursprung.
  Markiere am Ursprung eine waagerechte Tangente und den Hinweis f'(0)=0.

Vermeiden:
- Nicht behaupten, die Umkehrung gelte allgemein.
- Nicht schreiben, f'(x) = 0 auf einem ganzen Intervall fuer f(x)=x^3.
- Nicht aus f'(0)=0 folgern, dass f nicht streng steigend sei.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
