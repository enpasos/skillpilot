Beschreibung: Die lernende Person kann Konvergenzbedingungen geometrischer Reihen erläutern und den Grenzwert konvergenter geometrischer Reihen bestimmen.

Zusatzanweisung:
Pflichtinhalt:

Show the geometric series `a + aq + aq^2 + ...`.
State the convergence condition exactly: `|q| < 1`.
State the sum formula exactly: `S = a / (1 - q)`.
Use one correct example: `a = 3`, `q = 1/2`, so `3 + 1.5 + 0.75 + ... = 3 / (1 - 1/2) = 6`.
Also show a small warning panel: for `|q| >= 1`, no finite sum formula for an infinite geometric series.

Vermeiden:

Do not use `S = a / (1 + q)`.
Do not claim convergence for `q = 1` or `q = -1`.
Use no arrows. Use formula boxes and a simple table or bar shrinking illustration.
Do not mix finite and infinite sum formulas.
