```text
Titel: Parameter quadratischer Funktionen in Scheitelpunktform deuten
Beschreibung: Die lernende Person kann bei quadratischen Funktionen der Form a(x+d)^2+e die Wirkung der Parameter auf die Parabel beschreiben, die Anzahl der Nullstellen deuten und die zugehörige Gleichung in einfachen Fällen graphisch und rechnerisch einordnen.

Zusatzanweisung:
Required mathematical layout:
- Keep the image simple with exactly three panels for the vertex form f(x) = a(x - d)^2 + e.
- State clearly: vertex S(d|e).
- Panel "a": show a > 0 opens upward, a < 0 opens downward, |a| > 1 narrower, 0 < |a| < 1 wider.
- Panel "d": show horizontal shift only. With f(x)=a(x-d)^2+e, d > 0 shifts right, d < 0 shifts left.
- Panel "e": show vertical shift only. Use the same upward-opening parabola for e > 0 and e < 0; e > 0 shifts up, e < 0 shifts down.

Avoid:
- Do not use f(x)=a(x+d)^2+e.
- Do not make the e < 0 parabola open downward.
- Do not include root-count cases.
- Do not mix several different vertex-form conventions.
```
