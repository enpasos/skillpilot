## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Verfahren auf neue Beispiele übertragen
Beschreibung: Die lernende Person kann ein bekanntes Verfahren auf ein neues Beispiel übertragen, die Schritte anpassen und die Übertragung begründen.

Zusatzanweisung:
Pflichtinhalt:

- Zeige, wie ein bekanntes Verfahren auf ein neues Beispiel uebertragen wird.
- Links "Bekanntes Beispiel": "2x + 3 = 11", Schritte "-3", ":2", Ergebnis "x = 4".
- Rechts "Neues Beispiel": "3x + 5 = 20", angepasste Schritte "-5", ":3", Ergebnis "x = 5".
- In der Mitte ein Pfeil "Verfahren uebertragen".
- Unten kurze Begruendungskarte: "Konstante weg, dann durch Faktor teilen".
- Der Fokus liegt auf Anpassung der Schritte, nicht auf auswendig Kopieren.

Vermeiden:

- Keine falschen Loesungen.
- Keine unpassenden Schritte wie bei beiden Beispielen exakt dieselben Zahlen.
- Keine komplizierten Gleichungen oder Brueche.
- Keine Tool- oder CAS-Darstellung in diesem Bild.
```
