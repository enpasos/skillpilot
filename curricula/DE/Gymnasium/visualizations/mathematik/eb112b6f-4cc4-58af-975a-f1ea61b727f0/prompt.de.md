```text
Titel: Parabelbahnen mithilfe von Parametern darstellen (LK)
Beschreibung: Die lernende Person kann Parabelbahnen, zum Beispiel die Flugbahn eines Balls, mithilfe von Parametern darstellen und die Parameter in Bezug auf die Bewegungssituation deuten.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Parabelbahn eines Balls mithilfe eines Parameters darstellen und deuten.
- Verwende den Parameter t als Zeit in Sekunden mit 0 <= t <= 4.
- Parametergleichungen:
  x(t) = 2t
  y(t) = -t^2 + 4t
- Zeige eine Flugbahn im Koordinatensystem mit x-Achse "waagerechte Entfernung in m" und y-Achse "Hoehe in m".
- Markiere diese drei Punkte:
  t=0: P0(0|0), Start.
  t=2: S(4|4), Scheitelpunkt / hoechste Stelle.
  t=4: P4(8|0), Landung.
- Deutung:
  t bestimmt die Zeit.
  x(t) beschreibt die waagerechte Entfernung.
  y(t) beschreibt die Hoehe.
  Der Parameterbereich 0 <= t <= 4 beschreibt nur die sinnvolle Flugzeit.

Vermeiden:
- Den Scheitelpunkt nicht bei (2|4) einzeichnen; korrekt ist S(4|4), weil x(2)=4.
- Die Landung nicht bei x=4 markieren; korrekt ist P4(8|0).
- Keine negative Hoehe innerhalb des dargestellten sinnvollen Parameterbereichs zeigen.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
