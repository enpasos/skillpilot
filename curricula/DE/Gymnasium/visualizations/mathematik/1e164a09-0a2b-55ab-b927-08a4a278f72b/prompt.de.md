## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Plausibilität mit Beispielen testen
Beschreibung: Die lernende Person kann eine Aussage mithilfe geeigneter Beispiele sowie Rand- und Spezialfälle auf Plausibilität prüfen und die Wahl der Beispiele begründen.

Zusatzanweisung:
Required mathematical layout:
- Show the idea "Beispiele testen Plausibilität, sie sind noch kein Beweis".
- Use the statement: "n^2 + n ist gerade".
- Use a small table with exactly:
  - n = 1 -> 1^2 + 1 = 2
  - n = 2 -> 2^2 + 2 = 6
  - n = 3 -> 3^2 + 3 = 12
- Add a small note: "Randfall prüfen: n = 0 -> 0".
- End with a question mark card: "Muster plausibel - Beweis noch nötig".

Avoid:
- Do not claim that examples alone prove the statement.
- Do not introduce fractions, functions, or probability.
- Do not use wrong arithmetic in the table.
```
