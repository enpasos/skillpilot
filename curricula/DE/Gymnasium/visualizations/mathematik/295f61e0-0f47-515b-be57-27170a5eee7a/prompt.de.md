## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Vorwärts- und Rückwärtsarbeiten anwenden
Beschreibung: Die lernende Person kann Vorwärts- und Rückwärtsarbeiten als Strategie anwenden, Zwischenziele formulieren und aus einer Zielformulierung geeignete Schritte ableiten.

Zusatzanweisung:
Required mathematical layout:
- Show two arrows meeting in the middle:
  - Left arrow label: "Vorwärts: Gegebenes nutzen"
  - Right arrow label: "Rückwärts: Vom Ziel ausgehen"
- Use a simple target card: "Zeige: x = 6"
- Use a simple start card: "2x + 3 = 15"
- Show the middle step: "2x = 12"
- Add note: "Zwischenziel finden."

Visual guidance:
- Use a horizontal flow diagram, not a full worked solution page.
- Keep all algebra correct and readable.

Avoid:
- Do not solve to a value other than x = 6.
- Do not reverse the arrow directions.
- Do not add unrelated equations.
```
