## Prompt

```text
Bitte visualisiere das folgende Lernziel im einfachen Cartoon-Stil.

Rahmen:
- Zielgruppe: Gymnasium Mathematik.
- Erzeuge eine klare, gut lesbare Infografik im Querformat.
- Visualisiere genau dieses eine Lernziel; keine Zusatzthemen und keine Aufgabenlösung.
- Nutze plausible mathematische Beispiele nur, wenn sie das Lernziel unmittelbar erklären.
- Keine Drittanbieterlogos, keine Arbeitsblatt-Kopie, keine geschützten Figuren.
- Verwende wenig Text: kurze deutsche Labels statt langer Sätze.
- Beschriftungen und mathematische Schreibweisen müssen fachlich korrekt und auch in kleiner Darstellung lesbar sein.

Titel: Logische Schlussfolgerungen entwickeln
Beschreibung: Die lernende Person kann eigene Argumentationen strukturiert aufbauen, Schlussketten mit formalen oder anschaulichen Begründungen absichern und typische Beweismuster benennen.

Zusatzanweisung:
Pflichtinhalt:
- Thema: Eine logische Schlussfolgerung strukturiert entwickeln.
- Aussage: "Wenn n gerade ist, dann ist n^2 gerade."
- Zeige eine klare Schlusskette:
  1. Annahme: n ist gerade.
  2. Darstellung: n = 2k mit k als ganze Zahl.
  3. Quadrieren: n^2 = (2k)^2 = 4k^2.
  4. Umformen: 4k^2 = 2*(2k^2).
  5. Schluss: n^2 ist durch 2 teilbar, also gerade.
- Markiere die Beweisstruktur: Annahme -> Umformung -> Schluss.
- Optional: kleine Beispielkontrolle mit n=6, n^2=36 gerade.

Vermeiden:
- Keine Umkehrung der Aussage als bewiesen darstellen.
- Nicht von einem Beispiel allein auf den Beweis schliessen.
- Keine falsche Algebra bei (2k)^2.
- Keine technischen IDs, keine Produktnamen, keine Wasserzeichen.
```
