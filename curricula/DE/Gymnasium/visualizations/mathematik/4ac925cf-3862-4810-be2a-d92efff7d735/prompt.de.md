Beschreibung: Die lernende Person kann Wahrscheinlichkeiten verknüpfter Ereignisse aus Vierfeldertafeln und relativen Häufigkeiten ableiten, Additionsregeln begründen und Ergebnisse im Kontext interpretieren.

Zusatzanweisung:
Erzeuge genau eine fokussierte Infografik zum Berechnen von Wahrscheinlichkeiten verknüpfter Ereignisse aus einer Vierfeldertafel.

Kontext:
- Schulumfrage mit `100` Lernenden.
- Ereignis `A`: nimmt an der Sport-AG teil.
- Ereignis `B`: nimmt an der Musik-AG teil.

Pflichtinhalt:
- Eine konsistente Vierfeldertafel mit diesen Häufigkeiten:
  - `A ∩ B = 18`
  - `A ∩ nicht B = 22`
  - `nicht A ∩ B = 12`
  - `nicht A ∩ nicht B = 48`
  - Zeilensumme `A = 40`, Spaltensumme `B = 30`, Gesamt `100`.
- Berechnung: `P(A ∩ B) = 18/100 = 0,18`.
- Additionsregel: `P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 40/100 + 30/100 - 18/100 = 52/100 = 0,52`.
- Kurze Kontextdeutung: `52 %` sind in mindestens einer der beiden AGs.

Vermeiden:
- Keine Wurzelterme.
- Kein Baumdiagramm als Hauptdarstellung.
- Keine inkonsistenten Summen.
- Keine Verwechslung von `und` mit `oder`.

Layout:
- Einfacher Cartoon-Tafelstil, große lesbare Tabelle und zwei Rechenzeilen, keine Wasserzeichen.
