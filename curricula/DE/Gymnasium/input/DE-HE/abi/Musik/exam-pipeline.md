# Exam Pipeline Musik

Das Curriculum ist das kanonische Release-Artefakt.
Die beiden Offer-Anker `abi_gk_offer_2026` und `abi_lk_offer_2026` leben im Curriculum.
Master-Sets werden nur aus Offer-Aufgaben plus phasenlokalen Practice-Aufgaben abgeleitet.

Musik 2026 nutzt die offizielle Struktur:
- GK: zwei Analysevorschläge, einer wird bearbeitet
- LK: zwei Analysevorschläge und optional eine Gestaltungsaufgabe, einer wird bearbeitet

Die abgeleiteten Artefakte unter `abi/Musik/` sind Build- und QA-Hilfen, nicht der Release selbst.
