# ABI Biology Input Sources

This directory stores external example sources for the Hessen 2026 biology exam pipeline.

Purpose:
- capture source URLs and short metadata for inspiration and calibration
- extract recurring patterns for material-bound biology tasks
- avoid re-researching the same public example pools for every production cycle

Non-goal:
- no local copy of third-party task texts as our own authored tasks
- no verbatim reuse of task wording, material blocks, or solution text
- no plagiarism

Allowed use:
- derive task design patterns
- calibrate operator use, material types, data interpretation, and evaluation depth
- map source pools to curriculum areas and ABI-style expectations

Required rule for downstream authoring:
- every new SkillPilot biology task must be independently re-authored
- contexts, data framing, wording, and solution path must be newly constructed
- external sources may inform style and structure, but not be copied

Files:
- `source_catalog.json`: structured source manifest
- `pattern_notes.md`: abstracted didactic and assessment patterns

Primary source pools currently tracked:
- Bossert BCS biology Abitur examples and authoring notes
- IQB Sek II biology example tasks
