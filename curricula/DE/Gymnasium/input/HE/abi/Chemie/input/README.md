# ABI Chemistry Input Sources

This directory stores external example sources and official reference documents for the Hessen 2026 chemistry exam pipeline.

Purpose:
- keep official exam references and public example pools in one place
- calibrate chemistry task style, material types, and operator profiles
- derive independent SkillPilot tasks and later offer sets without redoing source research

Non-goal:
- no local copy of third-party example tasks as authored SkillPilot tasks
- no verbatim reuse of task wording, figures, tables, or solutions
- no plagiarism

Allowed use:
- source cataloging
- pattern extraction for material-bound chemistry tasks
- blueprint calibration against official 2026 focus topics

Required authoring rule:
- every future SkillPilot chemistry task must be independently re-authored
- contexts, numbers, material framing, and wording must be newly constructed
- external sources may calibrate style and structure, not be copied

Files:
- `source_catalog.json`: structured source manifest
- `pattern_notes.md`: abstracted authoring patterns

Primary source pools currently tracked:
- Hessen KCGO chemistry PDF
- Hessen Landesabitur 2026 chemistry section
- IQB Sek II chemistry example tasks
