# Alkanol-Oxidation: gezielte Korrektur einer tatsächlichen Bildschwäche

Das tatsächlich gesichtete Bestandsbild behauptet eine allgemeine Oxidierbarkeitsrangfolge und ein absolutes Oxidationsverbot für tertiäre Alkanole. Der PNG-Nachfolger macht die begrenzten Bedingungen ausdrücklich und bewahrt die korrekten Struktur-/Produktformeln.

Erstellt mit eingebautem `image_gen`, tatsächlicher Prompt unter `generation/prompt.actual.md`. Ganze ausgewählte Ziel-/P-Körper, exakte alte Bildbytes und tatsächliche 360/680-Pixel-Ansichten sind gebunden. Die unabhängige tatsächliche Komponentenprüfung steht aus. Noch keine Normalaktivierung, Bild-/M7-Freigabe, menschliche Zustimmung oder Lernendenleistung.
