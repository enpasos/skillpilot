# Nicht ausgewählter erster Modellversuch

Der Produktionsaufbau scheiterte am geschlossenen Schema von vier neuen
`decisionBasis`-Metadaten. Es entstand kein BookModel und kein Reviewvotum.
Die ganzen unveränderten P-Eingänge sowie die vorbereitete Konfiguration
bleiben erhalten. Die technische Normaldatenkorrektur verwendet den bereits
vorhandenen Post-Split-Enumwert und ändert keine fachliche Klassifikation.
Der tatsächliche Nachfolger wird separat unter `...-v2` aufgebaut.
