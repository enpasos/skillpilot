# Gemeinsamer Chemie-Integrationskandidat

Technische Zusammenführung von neun abgegrenzten Autorenpaketen, noch keine Normalaktivierung oder fachliche Abschlussfreigabe. Alle ganzen Vorher-Ziele müssen dem aktuellen kanonischen Stand entsprechen. Nur belegte Feldänderungen werden übernommen; unterschiedliche additive Listenänderungen werden unter Erhaltung ihrer Reihenfolge verbunden. Konflikte brechen ab.

Vier neue IDs aus den getrennten Chemiekompetenzen sind in diesem Zwischenkandidaten enthalten. Das aktuelle normale Zieluniversum bleibt 450. SN-Praxis ist ohne neue ID am bestehenden e81-Träger vorbereitet; Aluminium verwendet ebenfalls bestehende Ziele. Die explizit benannten finalen Fremdprüfungen und Quellenoperationen bleiben vor Aktivierung erforderlich. Der Kandidat darf deshalb nicht als finaler aktueller Lernzieltext oder als neuer strenger Abschluss gezählt werden.
