# Separate canonical scope judgment

Root asked whether an actual scientifically reviewed Grignard terminal may be represented in the canonical graph with the **same explicit excluded offer boundary** as its existing ordinary prerequisite, without a new national opt-in UI.

**Yes, in principle.** AGENTS separates durable competency/assessment semantics from program placement and learner target projection. The owner objective addresses the current curricularAtomic QA universe; an existing excluded voluntary atom still deserves coherent material and didactic dependencies. An excluded matching practice endpoint can supply canonical assessment structure without inventing an official curriculum duty, learner topic selection or a currently available learner offer.

The concrete successor must retain the ordinary ID/body/P/source disposition and `applicabilityProjection=excluded`, give the endpoint that same explicit exclusion, require/cover exactly `8edee6b6-9ead-515e-93f5-feada64522b2`, retain voluntary own-practice status and all real execution requirements, and insert no target reference that makes it a default offer. Actual current projections must demonstrate its exclusion. A canonical edge is not a live usable learner path or source-coverage authority; a green route check alone cannot change those meanings.

This opinion creates no source binding and approves no uninspected new author mutation. The FIRST above reviews the actual v6 content, whose currently absent target placement remains stated. A concrete excluded-boundary successor requires exact bounded scope/interface review before integration or a closure claim. No new runtime/UI work is needed merely to represent these canonical semantics, and none is authorized here.
