# Vorhandene Chemie-Bilder vollständig im Repository gebunden

Die vier bereits tatsächlich unabhängig geprüften Bildkorrekturen werden mit ihren bestehenden FIRST-Nachweisen in einen inaktiven QA-Nachfolger übernommen. 458 andere QA-Zeilen und alle menschlichen Prüffelder bleiben unverändert. Dies ist keine neue Bildprüfung.

Vier weitere bereits geprüfte PNGs waren nur in der bisherigen Ausführungsumgebung vorhanden. Ihre exakten Bytes sind hier gesichert und mit den eingecheckten ursprünglichen Bindungszeugen verglichen. Der neue Dateikatalog löst die bestehenden Bilder aller 439 fachlichen Kandidatenziele aus dem Repository auf.

Aktive kanonische Dateien, öffentliche Assets, die zentrale Registry und die aktive QA bleiben unverändert. Fachliche Materialien und finale Quellen-/Kontextintegration werden gesondert abgeschlossen; kein neuer globaler M7-Abschluss wird daraus abgeleitet.
