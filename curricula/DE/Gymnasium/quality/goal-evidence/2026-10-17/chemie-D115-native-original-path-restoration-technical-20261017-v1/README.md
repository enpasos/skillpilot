# D115: ursprüngliche native Beschreibungsdateien wieder erreichbar

Diese technische Integration stellt364 vom bestehenden D115-Register erwartete
Dateipfade im normalen Repository wieder her:72 relative Links auf bereits
committbare exakte Main-Transporte und292 unveränderte historische Dateien
(12,7MB).2285 weitere Dateien liegen bereits an ihren ursprünglichen Pfaden.

Vor jeder Änderung wurden SHA256 und Größe geprüft; abweichende historische
Dateien werden nicht überschrieben. Danach wurden alle2649 tatsächlichen
Stock-Dateibindungen und die Erreichbarkeit der115 Indizes geprüft.

Die Originalurteile,373 Supersessions, zwei Withdrawals und drei semantischen
Retirements bleiben exakt erhalten. Es gibt keine neue fachliche Prüfung,
Freigabe, Fingerprint- oder Registryänderung. Insbesondere beweist die
Wiederherstellung keine Gültigkeit historischer Bindungen im neuen finalen
Ziel-/Quellen-/View-Kontext. Alte M-/SEM-/P-Laufzeitkonfigurationen werden hier
nicht aktiviert. Ganze Bücher, PDFs und das große lokale Dateiinventar werden
nicht erneut in das Repository kopiert.
