# Historische abgebrochene lokale P5-Materialisierungen

Die beiden Unterverzeichnisse erhalten genau die tatsächlichen Fehler: zuerst eine unzulässige Großschreibung im technischenBezeichner, danach neun zu lange Kurzfelder. Keine fachliche Ablehnung, keine gültige P5-Materialisierung und kein M7-Abschluss. Die ursprünglichen unabhängigen Materialprüfungen bleiben erhalten; der technisch passende Kurzfeldnachfolger wird separat gebunden.
