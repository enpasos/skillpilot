## Case 1 — personal multi-field investigation

1. Teacher supplies fresh, separately coded C4, P7 and B, retains the code key, and supplies a separate known R7 aliquot from P7. One learner's actions must be attributable to that learner; a partner's execution cannot silently count for both.
2. Learner labels clean vessels and personally transfers fresh aliquots with dedicated pipettes. No used test piece, liquid or pipette returns to stock. In these cases the comparable conditions are clean separate aliquots, room conditions, adequate immersion, fresh indicator and matching scale. Equal drop counts are not a general goal requirement.
3. Learner uses fresh I1 for each sample and control. Per the current manufacturer's visual instructions: immerse all fields for 1 second, remove excess over the tray, compare the pattern with the original 92110 scale. Where buffering is insufficient, leave the strip in the sample until colours remain constant; record the actual condition/time. Do not infer the product's multi-field result from one chosen pad or the illustration.
4. Before consulting a code key or model answer, learner records personal raw observations: code, stock/preparation identifier, indicator product/lot/scale, actual sampling and application, observed field colours in order, temperature, immersion/reading conditions and observed control. Teacher records which actions they actually observed the learner performing. Photographs may supplement the dated written raw record; an old photograph or reference image cannot replace it.
5. Learner then matches their observed pattern to the original scale, states the closest broad region, classifies all three samples, explains limits, and notes ambiguity. Teacher reveals the code key after the independent inference. Diagnose disagreement honestly; never replace an observed colour with the expected one.
