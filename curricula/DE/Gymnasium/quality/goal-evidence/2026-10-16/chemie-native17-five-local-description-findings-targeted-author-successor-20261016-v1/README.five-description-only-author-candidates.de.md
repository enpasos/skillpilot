# Fünf gezielte Beschreibungsentwürfe

Vier fachliche Präzisierungen betreffen die tatsächlich bereits im positiven Vertrag angelegten Aspekte: vorläufige Komponenten-Zuordnung bei planarer Chromatografie; beobachtbarer Grignard-Reagenzeinsatz mit wasserfreier Addition und späterer Protonierung; mechanistisch begründete Routenwahl bei Friedel-Crafts; geeignete schwache Säure-Base-Paare und die pH/pOH-Zuordnung am Halbäquivalenzpunkt. Bei Pflanzenöl werden ausschließlich zwei fehlende Leerzeichen korrigiert.
