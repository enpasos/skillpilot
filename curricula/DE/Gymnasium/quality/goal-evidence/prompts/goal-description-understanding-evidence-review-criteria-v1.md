# Goal-description understanding-evidence review criteria v1

Apply every criterion independently to every assigned mathematics goal.

- **Exact curricular scope:** Preserve the competence claimed by the current
  title, descriptions, relations, and supplied source evidence. Clarification
  retains the current operations, representations, reasoning expectations,
  applications, and level of demand.
- **Essential understanding:** State the content-specific mathematical
  relationships, distinctions, structures, or meanings that organize the
  competence. The statement must be precise enough to guide both teaching and
  assessment for this exact goal.
- **Independently observable performance:** State what the learner independently
  does, explains, constructs, compares, interprets, or justifies so the essential
  understanding becomes observable. Name the relevant mathematical objects and
  relationships rather than using a generic phrase such as “shows
  understanding”.
- **Transfer to a fresh changed case:** State a structurally related variation
  in which the learner applies the same understanding. The case is changed in a
  content-relevant way and presented independently as a fresh task while staying
  within the goal's curricular scope.
- **Reasoned choice and comparison:** When alternatives, representations, model
  choices, or strategies are part of the competence, state the mathematical
  reasons, criteria, trade-offs, or limitations that make the learner's choice
  understandable.
- **Method neutrality:** Accept mathematically equivalent approaches. Require a
  particular method only when that method is itself the stated competence or is
  normatively source-bound.
- **Semantic atomicity:** Use `split_review` when several independently
  assessable goals need separate evidence expectations rather than placing them
  inside one longer replacement description.
- **Age and stage fit:** Keep language understandable at the stated Gymnasium
  stage while retaining mathematical precision and the existing level of
  demand.
- **DE/EN parity:** German and English descriptions and understanding-evidence
  fields express the same mathematical competence, relationships, expected
  independence, and transfer demand. Neither language adds or omits a facet.
- **Description/profile boundary:** Keep the replacement short and
  learner-facing. Concrete assessment cases, variation sequences, scoring
  rubrics, assistance history, and detailed evidence requirements belong in the
  `positive-understanding-evidence-v2` profile.
- **Profile contract and recommendation:** Set `evidenceProfileContract` to
  `positive-understanding-evidence-v2`. Use `none` when the supplied current
  profile under this contract already expresses the expected understanding,
  performance, and transfer completely; use `create` when such a profile is
  needed; and use `revise` when the supplied current profile should be aligned
  with this review. The recommendation remains non-authoritative.
- **Conservative revision:** Use `keep` when the current description is already
  adequate. Use `revise` only for a concrete, local improvement that an exact
  replacement delivers without broadening the goal.
- **No automatic authority:** Every AI record remains
  `candidate`/`ai_candidate`. Model agreement is neither human adjudication nor
  permission to mutate canonical curriculum data.

The visualization is teaching support. State the expected evidence as
learner-generated mathematical activity in an independently presented fresh
task, including a content-relevant variation for transfer.
