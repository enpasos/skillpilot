# Platinbild: begrenzte Katalysator-Korrektur

Der unabhängige Bildbefund betrifft die mittlere Trennschicht der PEM-Zelle. Das bearbeitete PNG zeigt nun eine helle Membran mit je einer dünnen hervorgehobenen Katalysatorfläche auf beiden Seiten; die zwei Zeiger enden auf diesen Flächen.

Original,360und680Pixel wurden tatsächlich betrachtet. Native1672×941PNG, bytegleich vom erhaltenen Generatororiginal kopiert. Erzabbau, Aufbereitung, Platinbeispiel und qualitative Diskussionsfaktoren sind im gleichen Bildaufbau erhalten; keine unveränderten Rasterpixel behauptet. Die anderen zwei akzeptierten Bilder bleiben unverändert.
