# Pythagoras-P-v2 nach Kehrsatzkorrektur

Die vier im [Vorgängerpaket](../math-m7-pythagoras-four-current-v1/README.md) fachlich geprüften P-v2-Kandidaten wurden an den aktuellen Canon und unveränderte Bildbytes neu gebunden. Drei Zieltexte blieben unverändert. Bei `6a3502ee` nennt der Canon jetzt ausdrücklich die Voraussetzung `a²+b²=c²` und den rechten Winkel gegenüber `c`. Beide unabhängigen Fälle des vorhandenen P-Profils enthielten diese Voraussetzung bereits; geprüft wurde erneut die nichtzirkuläre Folge: rechtes Hilfsdreieck mit Katheten `a,b`, `d²=a²+b²=c²`, positive Längen `d=c`, dann SSS. Das tatsächliche PNG zeigt diese Folge korrekt.

Materialisierer und P-v2-Check meldeten vier aktuelle `needs_human_review`-Records, 0 menschliche Freigaben und 0 Blocker. Der alte Batch bleibt als Diagnose der vorigen Formulierung erhalten; D muss auf dem revidierten Text unabhängig in zwei Runden geprüft werden.
