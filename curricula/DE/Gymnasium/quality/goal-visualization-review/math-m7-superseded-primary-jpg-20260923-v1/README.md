# Superseded Math JPG assets

This directory preserves the exact previous primary JPG of each goal listed in
`manifest.json`, named `<goalId>.jpg`. The active goal links and the canonical,
Web, and backend asset roots now use reviewed PNG replacements. These old JPGs
are retained solely as historical evidence for earlier review records and are
not an alternative current visualization or an approval.

For each goal, the archived JPG has the recorded SHA-256. Before archival, its
canonical, Web, and backend copies were byte-identical, and the three current
PNG copies existed and were byte-identical. Earlier review records remain
unchanged.
