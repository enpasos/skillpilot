# Rekonstruktion: Energien wasserstoffähnlicher Ein-Elektronensysteme

## Prompt

Hellblaue, gut lesbare Lerninfografik mit dem Titel „Energien wasserstoffähnlicher Ein-Elektronensysteme“. Formel Eₙ ≈ −13,6 eV · Z²/n²; Hinweislinien benennen die Energie des Niveaus n, Kernladungszahl Z und ganzzahlige Hauptquantenzahl n. Bezugspunkt ist die Ionisationsgrenze bei 0 eV.

Tabelle mit den Spalten Hauptquantenzahl n, Wasserstoff H (Z = 1), Helium-Ion He⁺ (Z = 2). Zeilen n = 1: −13,6 eV / −54,4 eV; n = 2: −3,40 eV / −13,6 eV; n = 3: −1,51 eV / −6,04 eV; n → ∞: 0 eV / 0 eV. Horizontale Vergleichspfeile markieren die Z²-Skalierung, keine Übergänge zwischen verschiedenen Atomen. „Doppeltes Z ⇒ vierfacher Betrag bei gleichem n (wegen Z²)“.

Modellbedingungen explizit: nichtrelativistisches Coulomb-Modell, ein Elektron, Kernbewegung vernachlässigt. Keine Mehr-Elektronen-Besetzung oder Pauli-Regel; diese Grafik betrifft ausschließlich die angegebenen Ein-Elektronensysteme. Informierte Kuration nach tatsächlicher Bildsichtung.
