## Offene inhaltliche Grenze vor einem Import

V4 zeigt die gegenseitige Aufhebung von `e^x` und `ln` an zwei Eingaben. Es zeigt **keinen Koordinatengraphen**, keine Punktevertauschung `(x,y) ↔ (y,x)` und **keine Spiegelung an `y=x`**. Daher darf ein späterer Alt-Text nur die Funktionsmaschinen und die Domäne `x>0` beschreiben, nicht eine sichtbare Graphspiegelung behaupten. Ob dieses Teilbild neben weiterem Unterrichtsmaterial das gesamte Lernziel didaktisch ausreichend stützt, muss in der aktuellen D-/P-/V-Bindung entschieden werden. Weder die bestandene Pixel-/Mobilprüfung noch dieses Archiv ersetzt diese Entscheidung.
