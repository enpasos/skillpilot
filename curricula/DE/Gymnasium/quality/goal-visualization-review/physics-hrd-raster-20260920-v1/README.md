wurde ebenfalls verworfen. Der hier gebundene PNG-Kandidat wurde mit der

ursprünglichen Visualisierung erstellt und anschließend in Originalauflösung
geprüft.

Rasterbild; es wird kein SVG-Produktionsasset veröffentlicht.
