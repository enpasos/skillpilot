Die `visualization:prepare`-Pakete wurden in diesem Durchgang **nach** der ersten Erzeugung für beide IDs angelegt; dies wird nicht als vorgezogener Vorbereitungsschritt ausgegeben. Die `visualization:import`-Läufe benannten den tatsächlichen Provider und jeweils letzten Prompt. Das aktive gemeinsame PNG hat SHA-256 `75f10fcf70cc0e3b7c2c34a1cabd50eab3d6f10657256e207210b948c53968f5`; Canon-, Public- und Backend-Kopien beider Ziele sind bytegleich.
