# Physics M7 PNG candidate batch: astro inference and waves

Review batch for 16 Physics learning goals. After independent content approval,
the selected candidates were authorized for a controlled native import into the
canonical landscape plus source/public/backend asset triplets. The central QA
registry and in-flight ledger are not mutated by this batch.

## Visual direction

- friendly, abstract, clear, comic-like didactic infographic
- opaque light cream background and dark legible text
- no photorealistic or sterile presentation
- short German labels only where they support the concept
- PNG candidates generated with the image generation workflow

Each selected `candidate.png` was inspected visually. Earlier variants and their
actual prompts are retained for corrected candidates. `manifest.json` is the
machine-readable hand-off for a separate central import and evidence-delta run.
