native gebundene Review-Export und beide Rundenunterlagen sind vorhanden.

neuer Abschluss in die zentrale Registry übernommen. Das Paket bleibt im
In-flight-Ledger reserviert; es wird weder verworfen noch erneut eröffnet.

und die beiden unabhängigen Runden sowie die positiven Evidenzfälle am
