**Supplied model source:** Two independently controlled sources emit in narrow red and blue spectral bands. An optical combiner can couple both light components into one fibre. At the receiving end a beam splitter sends incoming light to two branches. In the idealized model, a red filter passes only red and a blue filter only blue. A photosensitive receiver behind each filter converts time-varying intensity into an electrical signal. An unfiltered receiver responds to both colours. The model represents distinguishable channels, not the engineering design of an industrial multiplexer.
