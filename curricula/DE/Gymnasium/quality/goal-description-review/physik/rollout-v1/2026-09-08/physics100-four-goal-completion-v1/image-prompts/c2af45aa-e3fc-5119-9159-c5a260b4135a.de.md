Erzeuge eine einfache deutschsprachige didaktische FUNKTIONSGRAFIK zu einem bistabilen Transistor-Flipflop, KEIN elektrischer Schaltplan. Heller Hintergrund, Querformat. Zwei gleich große Zustandskarten nebeneinander. Karte links: „Zustand 1“, darunter vier exakt getrennte Zeilen „T1 leitet → C1 niedrig“, „C1 niedrig → T2 sperrt“, „T2 sperrt → C2 hoch“, „C2 hoch → T1 leitet“. Karte rechts: „Zustand 2“, darunter „T1 sperrt → C1 hoch“, „C1 hoch → T2 leitet“, „T2 leitet → C2 niedrig“, „C2 niedrig → T1 sperrt“. In beiden Karten zeigt ein dezenter Kreispfeil, dass die vier kausalen Aussagen einander stabilisieren. Zwischen den Karten ein eindeutiger gerichteter Pfeil von Zustand 1 zu Zustand 2, beschriftet „Basis B1 kurz auf 0 V ziehen“. Unterhalb großer kurzer Satz „Nach dem Impuls hält die Rückkopplung den neuen Zustand“. Titel „Bistabil: zwei gespeicherte Zustände“. Kleine Fußnote „Vereinfachtes Funktionsmodell einer geeigneten npn-Schaltung“. Keine NPN-Schaltsymbole, keine Widerstände, keine Verdrahtung, keine falschen Knoten, keine astabile Oszillation, keine technischen IDs. Große perfekt lesbare Schrift.
