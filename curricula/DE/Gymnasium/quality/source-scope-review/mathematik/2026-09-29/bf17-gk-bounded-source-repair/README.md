## Bounded P-v2 proposal for the single current BF17 goal

This is a proposed profile, not registered P evidence or approval. Use only candidates from the actual learner scope's source-backed family set. If the static assessment cannot carry that restriction honestly, these remain scope-specific examples; do not assert universal P completion.

1. **Warm-up toward a limit.** Give a new physical context with initial temperature 18 °C, a stable 80 °C environment, and observations of a fast initial rise that slows without overshoot. Offer plausible allowed families without prescribing the correct class. The learner must justify a bounded exponential combination such as `T(t)=80−62 exp(−kt)`, interpret 80 °C as the limiting temperature, 62 °C as the initial gap, and `k` in inverse-time units as the decay parameter of that gap. It is not a constant temperature-growth speed. The learner must identify the modeling assumptions; no invented measurement set is required for parameter meaning.
2. **Rise then decay.** Use a separate new signal/intensity context: zero at time zero, positive later, then one peak and a decline toward zero. From allowed candidates, the learner must justify a simple product such as `q(t)=A t exp(−kt)` against unbounded linear or monotone exponential alternatives. They must interpret `A` with quantity/time units as scaling and the initial slope, and `k` as the inverse-time decay parameter that affects the time scale. If an explicit calibrated instance is desired, provide one peak-time observation and one independent value and require their compatibility with the model; do not certify mastery from numeric substitution alone.

The two briefs test class selection and contextual parameter meaning independently. Neither asserts that this exact formula is a compulsory task in every state. Source-family admissibility remains a precondition, especially where the retained mapping is a combined partial reading. A fixed universal P case requires a separately checked common family; the current source repair has not claimed that check.
