# Q1-Routenreparatur nach ehrlicher Speicherbecken-Coverage

Vier eng begrenzte, eigene Prüfungsfälle prüfen die zuvor nur behaupteten Inhalte: Integralgraphen in beiden Richtungen (drei Ziele), Produktsummen und geometrischer Hauptsatz (zwei Ziele), Stetigkeitsbegründung des Hauptsatzes (LK, ein Ziel), transformierte und erweiterte Integrationsregeln (LK, zwei Ziele). Letzterer liefert auch eine echte Fortsetzungsroute für das GK/LK-Ziel transformierte Integranden; die Prüfungsaufgabe bleibt wegen ihrer weiteren LK-Regeln LK. Eine eigenständige GK-Prüfung dieser Regel bleibt außerhalb dieser begrenzten Reparatur zu prüfen.

Alle Musterlösungen wurden algebraisch nachgerechnet. Die Bestehensgrenze liegt jeweils einen Punkt unter der Maximalpunktzahl; jeder fehlende fachliche Kern wird im Punktschlüssel um mindestens zwei Punkte begrenzt. Diese Deckel sind Bewertungsanweisungen, keine serverseitigen Teilminimum-Regeln. Keine menschliche Freigabe oder reale Coach-Erprobung wird behauptet.
