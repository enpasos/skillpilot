# Approximate e using a stepwise growth model

A simplified growth model starts at $1$. One time unit is divided into
$n$ equal steps. At every step the current value is multiplied by
$1+1/n$. Let $a_n$ be the value after one whole time unit. As the steps
become finer, $a_n$ approaches Euler's number $e$. You are not asked to
prove this limit statement. A calculator or spreadsheet is allowed.
A total of **20 points** is available.

**1. Express the approximation method (3 points)**

Give an expression for $a_n$ and explain its base and exponent.
Using only the e-key or a memorised decimal does not replace calculating
with this method.

**2. Calculate approximations (6 points)**

Calculate $a_n$ for $n=1,10,100,1000,10000,100000$, giving six decimal
places. Document the expression or spreadsheet formula used for each value.

**3. State and qualify an approximation (3 points)**

Use your table to give an approximation of $e$ to three decimal places.
Explain what the final table entries suggest, and why finitely many values
alone provide neither the exact value nor a proved error guarantee.

**4. Interpret the constant (4 points)**

The natural exponential function is $f(t)=e^t$.
Explain the role of $e$ in this expression and state $f(0)$ and $f(1)$.
Distinguish the exact constant $e$ from your rounded decimal.

**5. Change the initial value (4 points)**

Now start the same model at $200$ instead of $1$.
Express the value after one time unit with $n$ steps and approximate it
using your value for $e$. Use the corresponding natural model
$B(t)=200e^t$ to explain which factor changes and why $e$ stays the same.
