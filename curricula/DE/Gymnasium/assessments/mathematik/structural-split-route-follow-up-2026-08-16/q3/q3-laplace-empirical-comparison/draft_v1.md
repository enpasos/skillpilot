# Laplace-Wahrscheinlichkeit und Versuchsdaten vergleichen

<a id="aufgabe"></a>
Ein fairer sechsseitiger Würfel wird mehrfach geworfen. Gezählt wird, wie oft eine Sechs fällt.

| Versuchszahl $n$ | Anzahl der Sechsen |
| ---: | ---: |
| 24 | 2 |
| 120 | 18 |
| 600 | 96 |

1. Bestimme für jede Versuchsreihe absolute und relative Häufigkeit der Sechs. (4 BE)
2. Bestimme die theoretische Laplace-Wahrscheinlichkeit für eine Sechs. (2 BE)
3. Vergleiche die drei empirischen Wahrscheinlichkeiten mit der theoretischen Wahrscheinlichkeit. (3 BE)
4. Erläutere anhand der Daten das empirische Gesetz der großen Zahlen. Erkläre ausdrücklich, warum es keine Garantie für eine einzelne Versuchsreihe liefert. (3 BE)
5. Beurteile die Aussage: „Nach genau 600 Würfen muss die relative Häufigkeit gleich $1/6$ sein.“ (2 BE)
