## Source Families

### WADI / Lehrerfortbildungsserver Baden-Württemberg

Use:

- diagnostic short-task style
- visible misconception design
- lean prompts that identify conceptual gaps quickly

Calibration takeaway:

- A good J5 package should include short, precise subparts that make misconceptions visible.
- Diagnostic quality comes from asking students to explain or correct a false claim, not from adding more routine calculations.

### IQB / VERA-8 Mathematics

Use:

- competency-oriented assessment structure
- representation and interpretation requirements
- balance between procedures and reasoning

Calibration takeaway:

- Even when the target year is J5, each larger task should include a small interpretation or validation step.
- A task set should make process competencies visible through wording such as `begründe`, `prüfe`, `interpretiere`, and `vergleiche`.

### SMART / Universität Bayreuth

Use:

- year-level navigation and broad gymnasium task-bank calibration
- topic breadth across J5-J10

Calibration takeaway:

- J5 tasks should remain compact and direct, but not purely procedural.
- Task packages should mix arithmetic, geometry, measurement, and simple data/representation work.

### LehrplanPLUS Bayern

Use:

- official year-level calibration
- competency language and progression check

Calibration takeaway:

- The J5 package should stay within natural numbers, simple whole-number contexts, early integers, basic geometry, measurement, tables, and first equation/inverse-operation ideas.
- Later concepts such as systematic fraction arithmetic, formal functions, roots, trigonometry, and algebraic transformations are out of scope.

---

## Design Implications for J5 Draft v1

- Use several coherent small contexts instead of one artificial mega-context.
- Start each task with an accessible action.
- Include at least one false-student-claim or misconception diagnosis.
- Require at least one representation change: table to calculation, coordinate description to sketch, map scale to real length, equation to verbal interpretation.
- Add age-appropriate model critique, for example rounding, space estimates, map-scale limits, or remainder decisions.
- Keep scoring transparent and observable.
