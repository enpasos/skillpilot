## Finding and Resolution

Task 4.2 prescribed the method with `Berechne mit einem Dreisatz ...`. This restriction is unnecessary in this context: Task 4.1 has already established the cost function, and the costs for 45 cards can be calculated correctly by evaluating that function or by equivalent proportional reasoning.

The v5 source therefore asks only `Berechne die Kosten für $45$ Karten.` It no longer requires one named presentation or calculation method. The expected value, the 2 BE allocation and the complete task total remain unchanged.

## Verification and Promotion

- The canonical task text and `draft_v5.md` use the same method-neutral wording.
- The matching solution still establishes the correct result $81\,\mathrm{EUR}$ without treating its displayed calculation as the only acceptable method.
- The stable goal ID, prerequisites, covered goals, demand levels, total points and passing threshold remain unchanged.
- Canonical Tasks 1-3 continue to reference `draft_v1.md`; Tasks 5 and 6 continue to reference `draft_v3.md`; Task 7 continues to reference `draft_v4.md`.
- All previously promoted source versions remain byte-unchanged.

With these conditions satisfied, Task 4 v5 is ready for promotion.
