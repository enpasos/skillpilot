## Why the current source gate can miss this

The canonical f76 competency has applicability for all sixteen jurisdictions and a BW-specific leaf source. Its ancestors include the general function strand and the J10 calculus cluster. An inherited mapping can establish that some source requirement is covered somewhere inside such a cluster; it does not establish that every descendant's entire completion contract is mandated at that source's stage. The direction and quantifiers differ.

There is concrete evidence of this overbroad propagation: Hamburg's year-7/8 source bullet about constant rate and starting value maps to the J10 derivative cluster `0fd96c54-c629-45aa-a640-e2718890ddf9`. Berlin's qualitative derivative bullet also maps to a broad function strand. Neither ancestor reference can independently justify f76's strict-sign theorem and non-converse. These findings identify a source/projection issue; manufacturing additional exams would only hide it from the completion-route check.
