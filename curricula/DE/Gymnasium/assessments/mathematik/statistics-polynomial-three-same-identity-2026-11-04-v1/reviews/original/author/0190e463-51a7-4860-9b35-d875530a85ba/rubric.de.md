# Eine Gesamtbewertung

20 BE insgesamt; **bestanden ab 15 BE**, sonst nicht bestanden. Es gibt genau
eine Gesamtentscheidung und keine getrennten Teilbestehensgrenzen.
Mathematisch gleichwertige Verfahren, Schreibweisen und knappe richtige
Erklärungen erhalten gleichen Kredit, unabhängig vom Ort in der Abgabe.
Identische Leistungen nur einmal werten. Teilpunkte wie angegeben, sonst
0,5 BE für eine sinnvolle unvollständige Teilleistung. Einen lokalen Fehler
nicht mehrfach bestrafen; nachvollziehbare richtige Folgearbeit zählt.
Zahlen auf etwa vier Dezimalstellen oder gleichwertige Genauigkeit runden;
Grenzentscheidungen mit ausreichender Genauigkeit treffen.

| Kriterium | BE |
|---|---:|
| f(-x) richtig (1); beide Symmetrieentscheidungen begründet (1); gerade Struktur einschließlich Konstantem erklärt (1). | 3 |
| g(-x) richtig (1); beide Symmetrieentscheidungen begründet (1); ungerade Struktur erklärt (1). | 3 |
| h(-x) richtig (1); beide Identitäten verworfen (1); gemischte nicht verschwindende Struktur erklärt (1). | 3 |
| Umformung oder gleichwertige direkte Einsetzung (2); y-Achse ja, Ursprung nein begründet (1); Aufhebung der linearen Summanden bzw. gleichwertige Strukturbegründung (1). | 4 |
| Beide Koeffizientenregeln einschließlich Exponent 0 (1,5); v nur y-Achse (0,5); Nullfunktion beide (1). | 3 |
| Je falsche Behauptung ein passendes überprüftes Gegenbeispiel mit Erklärung (je 2). | 4 |

Kappe die Gesamtpunktzahl auf höchstens 14 BE, wenn in der gesamten Abgabe eine der beiden im Kompetenzvertrag genannten Prüfweisen vollständig fehlt: Es gibt entweder keine tragfähige rechnerische Prüfung einer Symmetrieidentität oder keine tragfähige Erklärung aus der zusammengefassten Termstruktur. Reines Etikettieren als „gerade/ungerade“ ohne erkennbaren Zusammenhang genügt nicht. Eine korrekte Gleichungskette mit kurzer Strukturbegründung an beliebiger Stelle genügt; nicht jede Teilaufgabe muss dieselbe Erklärung wiederholen. Ein lokaler Vorzeichenfehler, ein einzelner falsch eingeordneter Sonderfall oder ein knappes richtiges Argument löst allein keine Kappung aus.

Nach einer gegebenenfalls anwendbaren Kappung wird nur die eine Gesamtpunktzahl mit 15 BE verglichen.
