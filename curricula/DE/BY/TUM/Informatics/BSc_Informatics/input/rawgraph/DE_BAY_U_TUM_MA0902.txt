# MA0902 Analysis for Informatics - rawgraph breakdown

Node: Analysis for Informatics (MA0902)
Description: The learner can apply core concepts of real analysis and calculus.

  Node: Real numbers and sequences
  Description: The learner can reason about real numbers and sequence convergence.

    Node: Order and completeness
    Description: The learner can use order properties, infimum/supremum, and density.

    Node: Sequence convergence and asymptotics
    Description: The learner can analyze convergence, monotonicity, and asymptotic behavior of sequences.

  Node: Series
  Description: The learner can analyze convergence of series.

    Node: Convergence tests
    Description: The learner can apply convergence and absolute convergence tests for series.

    Node: Power series and Cauchy product
    Description: The learner can work with power series and Cauchy products.

  Node: Continuity and functions
  Description: The learner can apply continuity concepts to functions.

    Node: Continuity and extrema
    Description: The learner can apply the intermediate value theorem and analyze extrema.

    Node: Inverse functions and compactness
    Description: The learner can analyze inverse functions and compactness-based results.

  Node: Differential calculus in one variable
  Description: The learner can compute derivatives and analyze functions.

    Node: Derivative rules and mean value theorem
    Description: The learner can apply derivative rules and the mean value theorem.

    Node: Taylor series and l'Hospital
    Description: The learner can use Taylor series and l'Hospital's rule for analysis.

  Node: Integral calculus in one variable
  Description: The learner can compute and apply integrals.

    Node: Fundamental theorem and antiderivatives
    Description: The learner can apply the fundamental theorem and find antiderivatives.

    Node: Integration techniques and improper integrals
    Description: The learner can use substitution, integration by parts, and improper integrals.

  Node: Multivariable calculus
  Description: The learner can compute derivatives in several variables.

    Node: Partial derivatives and gradient
    Description: The learner can compute partial derivatives, gradients, and Hessians.

    Node: Local extrema and curves
    Description: The learner can analyze local extrema and simple curve properties.

  Node: Differential equations
  Description: The learner can solve basic ordinary differential equations.

    Node: ODE classification and examples
    Description: The learner can classify ODEs and interpret basic examples.

    Node: Separable and linear ODEs
    Description: The learner can solve separable and linear differential equations.
