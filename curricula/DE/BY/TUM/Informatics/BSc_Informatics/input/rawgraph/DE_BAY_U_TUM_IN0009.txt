# IN0009 Basic Principles: Operating Systems and System Software - rawgraph breakdown

Node: Basic Principles: Operating Systems and System Software (IN0009)
Description: The learner can explain operating system concepts and system software components.

  Node: Operating system fundamentals
  Description: The learner can describe OS roles and abstractions.

    Node: OS structure and services
    Description: The learner can explain OS services and layered organization.

    Node: System interfaces
    Description: The learner can describe system calls and OS interfaces.

  Node: Processes and concurrency
  Description: The learner can manage processes and concurrency challenges.

    Node: Process management
    Description: The learner can describe process states and scheduling basics.

    Node: Synchronization and deadlocks
    Description: The learner can analyze synchronization, mutual exclusion, and deadlocks.

  Node: Memory and resource management
  Description: The learner can explain memory management concepts.

    Node: Address spaces and allocation
    Description: The learner can describe memory allocation and address spaces.

    Node: Virtual memory basics
    Description: The learner can explain virtual memory concepts and paging at a high level.

  Node: System programming and I/O
  Description: The learner can implement low-level system programs and handle I/O.

    Node: Low-level programming in C
    Description: The learner can write system-level code in C for processes and communication.

    Node: I/O and device interaction
    Description: The learner can describe I/O management and device interaction.

  Node: System software toolchain
  Description: The learner can describe how system software builds and runs programs.

    Node: Compiler, linker, loader roles
    Description: The learner can explain compilation, linking, and loading stages.

    Node: Libraries and build integration
    Description: The learner can describe library integration and build workflows.

  Node: Formal models for concurrency
  Description: The learner can use abstract models to reason about concurrency.

    Node: Petri nets and formal models
    Description: The learner can explain Petri nets and their use for concurrency modeling.

    Node: Parallel programming concepts
    Description: The learner can describe core concepts of parallel programming.
