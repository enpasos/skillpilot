# IN0005 Basic Practical Course: Computer Architecture - rawgraph breakdown

Node: Basic Practical Course: Computer Architecture (IN0005)
Description: The learner can analyze program performance and apply hardware-aware optimizations in practice.

  Node: Performance analysis and measurement
  Description: The learner can measure and analyze performance characteristics of programs.

    Node: Benchmarking techniques
    Description: The learner can design and run benchmarks to compare performance.

    Node: Profiling tools and counters
    Description: The learner can use profiling tools and hardware performance counters.

  Node: Systems programming in C
  Description: The learner can implement and debug low-level programs in C.

    Node: C basics: data structures and pointers
    Description: The learner can use C data structures, strings, pointers, and I/O.

    Node: Build and debugging workflows
    Description: The learner can use makefiles, assertions, and debuggers such as GDB.

  Node: Compiler and ABI considerations
  Description: The learner can account for compiler behavior and ABI constraints.

    Node: Compiler optimizations and defined behavior
    Description: The learner can explain basic compiler optimizations and defined behavior constraints.

    Node: ABI and annotation effects
    Description: The learner can relate ABI rules and annotations (aliasing, alignment) to performance.

  Node: Parallelism and SIMD
  Description: The learner can exploit parallelism at the instruction and thread level.

    Node: Parallel programming models
    Description: The learner can describe Flynn's taxonomy and basic parallel models.

    Node: SIMD and instruction-level parallelism
    Description: The learner can use SIMD concepts and reason about instruction-level parallelism.

  Node: Hardware-aware optimization projects
  Description: The learner can apply optimizations for modern architectures and accelerators.

    Node: Multithreading and synchronization
    Description: The learner can implement multithreading with Pthreads or OpenMP and use synchronization primitives.

    Node: Cache and heterogeneous systems
    Description: The learner can optimize for caches and program heterogeneous systems such as GPUs or FPGAs.
