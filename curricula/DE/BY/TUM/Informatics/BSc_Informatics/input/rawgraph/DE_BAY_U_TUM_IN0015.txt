# IN0015 Discrete Structures - rawgraph breakdown

Node: Discrete Structures (IN0015)
Description: The learner can apply discrete mathematical concepts in computer science contexts.

  Node: Sets, relations, and functions
  Description: The learner can work with foundational discrete structures.

    Node: Set operations and counting
    Description: The learner can apply set operations, equivalence laws, and basic counting.

    Node: Relations and relational algebra
    Description: The learner can analyze relations, joins, and transitive closure.

    Node: Functions and inverses
    Description: The learner can work with functions, composition, and inverse functions.

  Node: Propositional and first-order logic
  Description: The learner can model problems using logic.

    Node: Syntax and semantics
    Description: The learner can interpret logical formulas and truth tables.

    Node: Normal forms and SAT
    Description: The learner can derive CNF/DNF and apply SAT techniques such as DPLL and resolution.

    Node: Predicate logic modeling
    Description: The learner can model problems using first-order predicate logic.

  Node: Combinatorics
  Description: The learner can solve counting and distribution problems.

    Node: Counting principles and binomial coefficients
    Description: The learner can apply basic counting principles and binomial identities.

    Node: Permutations, combinations, and distributions
    Description: The learner can solve problems involving permutations, combinations, and distributions.

    Node: Stirling numbers and partitions
    Description: The learner can use Stirling numbers and integer partitions in counting problems.

  Node: Graph theory
  Description: The learner can model and solve problems with graphs.

    Node: Graph basics and trees
    Description: The learner can define graphs, paths, and trees and use basic properties.

    Node: Euler and Hamilton cycles, planarity
    Description: The learner can analyze Euler and Hamilton properties and planarity criteria.

    Node: Matchings and stable matchings
    Description: The learner can solve matching problems including stable matchings.

  Node: Algebra and number theory
  Description: The learner can apply algebraic structures and number theory basics.

    Node: Groups, rings, and fields
    Description: The learner can define groups, rings, and fields and apply basic properties.

    Node: Lagrange theorem and cyclic groups
    Description: The learner can apply Lagrange's theorem and analyze cyclic groups.

    Node: Number theory and RSA
    Description: The learner can compute gcds, Euler phi, and explain RSA fundamentals.
