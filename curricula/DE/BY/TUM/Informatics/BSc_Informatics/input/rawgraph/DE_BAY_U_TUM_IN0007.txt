# IN0007 Fundamentals of Algorithms and Data Structures - rawgraph breakdown

Node: Fundamentals of Algorithms and Data Structures (IN0007)
Description: The learner can analyze algorithms and implement core data structures.

  Node: Complexity and algorithm analysis
  Description: The learner can use asymptotic analysis to evaluate algorithms.

    Node: Asymptotic notation and models
    Description: The learner can use Big-O style notation and basic computation models.

    Node: Efficiency analysis
    Description: The learner can analyze time and space complexity for algorithms.

  Node: Sequence data structures
  Description: The learner can implement and analyze sequence-based structures.

    Node: Dynamic arrays and lists
    Description: The learner can implement arrays and lists and compare operation costs.

    Node: Stacks and queues
    Description: The learner can implement stacks and queues and analyze their operations.

  Node: Hashing
  Description: The learner can apply hashing strategies for efficient lookup.

    Node: Chaining and probing
    Description: The learner can implement hashing with chaining and probing methods.

    Node: Universal and perfect hashing
    Description: The learner can explain universal hashing and apply perfect hashing ideas.

  Node: Sorting and selection
  Description: The learner can compare and analyze sorting algorithms.

    Node: Basic sorting algorithms
    Description: The learner can implement insertion, selection, and bubble sort.

    Node: Advanced sorting algorithms
    Description: The learner can analyze merge sort, heap sort, and quick sort and discuss lower bounds.

  Node: Priority queues and heaps
  Description: The learner can use heap-based priority queues.

    Node: Binary and binomial heaps
    Description: The learner can implement binary heaps and describe binomial heaps.

    Node: Priority queue operations
    Description: The learner can apply heap operations to priority queue problems.

  Node: Search trees
  Description: The learner can use tree-based search structures.

    Node: Binary search trees
    Description: The learner can implement binary search trees and analyze operations.

    Node: Balanced search trees
    Description: The learner can describe AVL trees and (a,b)-trees and their balancing.

  Node: Graph algorithms
  Description: The learner can model problems with graphs and apply standard algorithms.

    Node: Graph representations and traversals
    Description: The learner can represent graphs and perform DFS/BFS traversals.

    Node: Shortest paths and spanning trees
    Description: The learner can compute shortest paths and minimum spanning trees and use topological sorting.

  Node: Optional topics
  Description: The learner can recognize additional algorithmic techniques.

    Node: Data compression basics
    Description: The learner can explain Huffman and Lempel-Ziv style compression.

    Node: Pattern matching basics
    Description: The learner can describe simple pattern matching algorithms.
