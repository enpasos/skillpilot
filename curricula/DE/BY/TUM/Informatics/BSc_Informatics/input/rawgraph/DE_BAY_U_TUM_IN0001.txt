# IN0001 Introduction to Informatics - rawgraph breakdown

Node: Introduction to Informatics (IN0001)
Description: The learner can explain foundational computing concepts and implement basic programs in an object-oriented language.

  Node: Computing concepts and imperative programming
  Description: The learner can relate problems, algorithms, and programs and use imperative constructs.

    Node: Problem, algorithm, program
    Description: The learner can define and distinguish problems, algorithms, and programs and map problems to algorithms.

    Node: Imperative control structures
    Description: The learner can use sequence, selection, and iteration to build small programs.

    Node: Basic efficiency reasoning
    Description: The learner can reason about time and space use at a basic level.

  Node: Syntax and semantics of programs
  Description: The learner can describe formal syntax and basic execution models for programs.

    Node: Regular expressions and context-free grammars
    Description: The learner can use regular expressions and context-free grammars to specify syntax.

    Node: Control-flow and program semantics
    Description: The learner can interpret control-flow graphs and explain basic program semantics.

  Node: Elementary data structures and algorithms
  Description: The learner can use basic data types, arrays, and simple algorithms.

    Node: Numbers, strings, and arrays
    Description: The learner can represent and manipulate numbers, strings, and arrays.

    Node: Insertion sort
    Description: The learner can implement insertion sort and explain its behavior.

  Node: Recursion and search
  Description: The learner can design recursive solutions and analyze their behavior.

    Node: Binary search
    Description: The learner can implement binary search and analyze its correctness.

    Node: Types of recursion
    Description: The learner can identify common recursion patterns and trace recursive calls.

  Node: Object-oriented programming
  Description: The learner can apply core object-oriented concepts to structure programs.

    Node: Classes, objects, and methods
    Description: The learner can define classes and use objects and methods effectively.

    Node: Inheritance and interfaces
    Description: The learner can apply inheritance, abstract classes, and interfaces.

    Node: Polymorphism
    Description: The learner can use polymorphism and dynamic dispatch in program design.

  Node: Programming in the large and concurrency
  Description: The learner can relate programming to larger systems and basic concurrency.

    Node: Programming in the large
    Description: The learner can describe modularization and broader societal or ethical context.

    Node: Threads and basic concurrency
    Description: The learner can create threads and explain basic concurrency issues.
