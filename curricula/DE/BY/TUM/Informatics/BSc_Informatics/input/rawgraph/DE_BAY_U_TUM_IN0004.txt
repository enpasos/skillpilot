# IN0004 Introduction to Computer Organization and Technology - Computer Architecture - rawgraph breakdown

Node: Introduction to Computer Organization and Technology - Computer Architecture (IN0004)
Description: The learner can explain computer system organization and basic hardware-software interactions.

  Node: Computer system organization
  Description: The learner can describe layered system structure and the instruction cycle.

    Node: Von Neumann model and instruction cycle
    Description: The learner can explain the Von Neumann architecture and the machine instruction cycle.

    Node: Hardware-software interface
    Description: The learner can describe how software interacts with hardware abstractions.

  Node: Instruction set architecture and assembly
  Description: The learner can work with ISA concepts and simple assembly programming.

    Node: ISA concepts and instructions
    Description: The learner can describe instruction formats and execution behavior.

    Node: Assembly programming and calling conventions
    Description: The learner can write simple assembly code and apply calling conventions.

  Node: Microprogramming and control
  Description: The learner can explain how instructions are implemented in control units.

    Node: Microprogrammed control
    Description: The learner can outline microprogramming principles for instruction execution.

    Node: Instruction implementation
    Description: The learner can trace how machine instructions are realized at the micro level.

  Node: Digital logic and hardware design
  Description: The learner can model combinational and sequential circuits.

    Node: Combinational and sequential circuits
    Description: The learner can analyze basic circuits and state elements.

    Node: VHDL-based design
    Description: The learner can describe hardware behavior using a formal language such as VHDL.

  Node: Processor and system architectures
  Description: The learner can classify processors and system architectures.

    Node: Microprocessor and system architectures
    Description: The learner can compare microprocessor and system architecture concepts.

    Node: Memory, I/O, and parallel systems
    Description: The learner can explain memory systems, I/O, and parallel or distributed systems at a high level.
