# IN0008 Fundamentals of Databases - rawgraph breakdown

Node: Fundamentals of Databases (IN0008)
Description: The learner can design, query, and operate relational database systems.

  Node: Relational model and SQL
  Description: The learner can work with relational data models and SQL.

    Node: Relational concepts and integrity
    Description: The learner can explain relations, keys, and integrity constraints.

    Node: SQL querying
    Description: The learner can write SQL queries, including joins and aggregations.

  Node: Database design
  Description: The learner can design databases from conceptual to physical schemas.

    Node: Conceptual and logical design
    Description: The learner can create schema designs from conceptual models.

    Node: Normalization and design theory
    Description: The learner can apply relational design theory and normalization.

  Node: Physical storage and indexing
  Description: The learner can explain physical data organization and indexes.

    Node: Storage organization
    Description: The learner can describe storage layouts and access methods.

    Node: Index structures
    Description: The learner can explain index structures and their use cases.

  Node: Query processing and optimization
  Description: The learner can understand query execution and optimization.

    Node: Relational algebra and query plans
    Description: The learner can translate queries into relational algebra and execution plans.

    Node: Logical and physical optimization
    Description: The learner can explain basic optimization techniques for queries.

  Node: Transactions and recovery
  Description: The learner can ensure correctness in multi-user environments.

    Node: Transaction management and concurrency control
    Description: The learner can explain transactions, isolation, and concurrency control.

    Node: Recovery and backup
    Description: The learner can explain recovery, backup, and fault handling.

  Node: Security and authorization
  Description: The learner can apply security controls in database systems.

    Node: Authorization mechanisms
    Description: The learner can apply authorization and access control in databases.

    Node: Secure multi-user operation
    Description: The learner can explain secure operation in multi-user settings.

  Node: XML data modeling
  Description: The learner can model data beyond the relational model.

    Node: XML modeling basics
    Description: The learner can describe basic XML data modeling concepts.
