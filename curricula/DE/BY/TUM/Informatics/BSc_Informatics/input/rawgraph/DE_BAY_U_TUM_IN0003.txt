# IN0003 Functional Programming and Verification - rawgraph breakdown

Node: Functional Programming and Verification (IN0003)
Description: The learner can program in a functional style and apply basic verification techniques.

  Node: Verification of imperative programs
  Description: The learner can reason about correctness and termination of imperative programs.

    Node: Hoare and Floyd verification
    Description: The learner can apply Hoare or Floyd logic to prove partial correctness.

    Node: Termination and procedures
    Description: The learner can argue about termination and verify simple procedures.

  Description: The learner can use core functional programming concepts.

    Node: Values, variables, and functions
    Description: The learner can define functions and evaluate expressions in a functional language.

    Node: Data structures and pattern matching
    Description: The learner can model data and use pattern matching to process it.

  Description: The learner can use advanced functional abstraction mechanisms.

    Node: Higher-order functions and polymorphic types

    Node: Modules, structures, and functors
    Description: The learner can organize programs using modules, structures, and functors.

  Node: Semantics and verification of functional programs
  Description: The learner can connect functional semantics with verification tasks.

    Node: Semantics of functional programs

    Node: Verification of functional programs
