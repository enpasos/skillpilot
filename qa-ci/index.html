    QA/CI Documentation

    This page is the public entry point for SkillPilot curriculum-quality and validation documentation. It is intended to be reachable on GitHub Pages at /skillpilot/qa-ci/.

    Use this page by role: start with the overview documents, then jump to a review lane, generated status artifact, or pilot dossier as needed.

    Start Here

    • Curriculum Quality: Reifegrade, QA-Scopes und CQR-Regeln Detailed meaning of M0 to M7, QA scopes, routes, terminal autonomy, and CQR-* rules.
    • CI Overview Local and GitHub Actions validation entry points.
    • Graph Validation Rules Single source of truth for algorithmic graph validation in CI.
    • Curriculum Package Readiness Fail-closed distinction between legacy export validation and the standalone JSON runtime profile.
    • Curriculum Release Model Conformance Real Mathematik compilation into the strict unpacked runtime model, including closure, migration, semantic kinds, digests, resources, QA, and remaining package gates.
    • Dual Curriculum Release Contracts Field/RDF semantics, canonical content digest, equivalence evidence, and paired release-index gates.
    • Curriculum Quality Dashboard Persisted status layer used by the local Workbench dashboard.
    • Curriculum Mapping Workbench Two-pane audit surface from source snapshots to learner-facing SkillPilot trees.
    • Documentation Guidelines Rules for document roles, generated artifacts, runbooks, and dated pilot records.

    Review Lanes

    These pages describe durable manual or semi-automated review processes. Their ledgers or configs are the source of truth; generated status pages are not.

    • Curriculum Package Human Review Gates Central release checklist for visualization quality, redistribution rights, source-text verification, ontology semantics, and stable promotion.
    • Semantic Atomicity Review Review process for deciding whether technical content leaves are semantically atomic.
    • Requires Review Process Manual QA workflow for prerequisite quality on atomic goals.
    • Atomic Review Process Older atomic-goal review workflow reference.
    • Relation Checks Relation-check scope and CI enforcement profile.
    • MEM SPARQL Consistency Audit Durable process reference for the non-blocking live MEM/FWU endpoint comparison.
    • MEM SPARQL Consistency Runbook Operational checklist for running the audit, reading the queue, and writing ledger decisions.
    • Goal Source Rationales Runbook Operational checklist for generating and reviewing human-readable source rationales.
    • Goal Feedback: Production-to-Codex Intake Default-off production inbox, digest-bound local custody transfer, online deletion, and candidate-only critical triage.
