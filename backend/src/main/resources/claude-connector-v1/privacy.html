Deutsch

Diese Datenschutzerklärung informiert über die Verarbeitung personenbezogener bzw. pseudonymer Daten bei der Nutzung des SkillPilot Claude Connectors.

Ergänzend gilt die allgemeine SkillPilot-Datenschutzerklärung.

Wichtiger Hinweis zum Mindestalter (18+):
Die Nutzung dieses Connectors über Claude.ai / Anthropic richtet sich nach den Nutzungsbedingungen von Anthropic ausschließlich an volljährige Personen (ab 18 Jahren).

1. Verantwortliche Stelle

Verantwortlich für die Datenverarbeitung auf den Systemen von SkillPilot ist die enpasos – Enterprise Patterns & Solutions GmbH, Heuhohlweg 42, D-61462 Königstein. Datenschutzanfragen: support@skillpilot.com.

2. Zweck und Funktionsweise der Datenverarbeitung

Der SkillPilot Claude Connector ermöglicht es volljährigen Lernenden, ihren bestehenden pseudonymen SkillPilot-Lernstand in Anthropic Claude für personalisiertes KI-Coaching zu nutzen.

  • Start ausschließlich bei SkillPilot: Eine neue Lernsitzung wird über Lernen starten in der gemeinsamen SkillPilot-Weboberfläche vorbereitet. Die permanente SkillPilot-ID bleibt dabei in der SkillPilot-Weboberfläche und im SkillPilot-Core.
  • Zeitlich begrenzte Lernsitzung: Claude erhält in der vorbereiteten Startnachricht nur eine zufällige, opake Sitzungskennung. SkillPilot übergibt diese Nachricht nach Ihrer ausdrücklichen Auswahl über den einzigen q-Parameter von https://claude.ai/new an das Eingabefeld; Claude sendet sie nicht automatisch. Die Kennung ist ab ihrer Ausgabe genau 24 Stunden gültig und kann in Claude weder verlängert noch erneuert werden.
  • Getrennte Berechtigungen: Die OAuth-Verbindung authentifiziert nur das installierte Plugin bzw. den Connector. Sie enthält keine permanente SkillPilot-ID und wählt keinen Lernstand aus. Auf Lernstandsdaten kann der Connector nur mit einer zusätzlich gültigen 24-Stunden-Sitzungskennung zugreifen.
  • Keine Weitergabe der permanenten ID: Claude und Anthropic erhalten zu keinem Zeitpunkt die permanente SkillPilot-ID, eine SkillPilot-ID-Datei oder deren Passwort.

3. An Claude übermittelte Daten

Während einer Coaching-Sitzung in Claude ruft das System über standardisierte MCP-Tools projektbezogene Lernstandsdaten ab:

  • Aktuelles Thema und Lernziele des gewählten Curriculums
  • Planbezogener Tagesstand pro Fach: heute vorgesehene, davon bereits beherrschte und noch offene Lernziele sowie offene Rückstände; Plan- und Landschaftskennungen werden nicht an Claude übermittelt
  • Lernstand und Mastery-Werte (ohne persönliche Klartextidentifikatoren)
  • Ergebnisse von Überprüfungen (Verified Recall / Prüfungsbewertungen)

4. Speicherdauer und Widerruf (Revocation)

Die klare Sitzungskennung wird nicht gespeichert; SkillPilot speichert nur ihren anbieterspezifischen HMAC-Prüfwert. Jede normale Lernsitzung endet absolut nach 24 Stunden. Sitzungsgebundene Idempotenz- und Sicherheitsnachweise enden spätestens mit der zugehörigen Lernsitzung. Abgelaufene Datensätze werden regelmäßig entfernt.

OAuth-Access-Token für die rein technische Plugin-Verbindung sind kurzlebig; die derzeit vorgesehene Gültigkeit beträgt höchstens eine Stunde. Rotierende Refresh-Tokens sind derzeit höchstens 30 Tage gültig. Eine Erneuerung dieser technischen Verbindung verlängert keine Lernsitzung und stellt keinen Lernstandszugriff her.

Sie können die technische Verbindung über die von Claude aufgerufene OAuth-Revocation-Schnittstelle trennen. Dabei werden die zugehörigen OAuth-Autorisierungen ungültig. Der eigentliche SkillPilot-Lernstand, die permanente SkillPilot-ID und Verbindungen anderer Anbieter bleiben unverändert.

5. Datenverarbeitung durch Anthropic

Für die Datenverarbeitung innerhalb von Claude (Prompts, Antworten, Chatverlauf) gelten zusätzlich die Nutzungsbedingungen und Datenschutzbestimmungen von Anthropic.

English

This Privacy Policy explains how personal or pseudonymous data is processed when you use the SkillPilot Claude Connector.

The general SkillPilot Privacy Policy also applies.

Important minimum-age notice (18+):
Under Anthropic's terms of service, this connector is intended exclusively for adults aged 18 or older when used through Claude.ai / Anthropic.

1. Controller

The controller for data processing on SkillPilot systems is enpasos – Enterprise Patterns & Solutions GmbH, Heuhohlweg 42, D-61462 Königstein, Germany. Privacy requests: support@skillpilot.com.

2. Purpose and operation of data processing

The SkillPilot Claude Connector enables adult learners to use their existing pseudonymous SkillPilot learning state in Anthropic Claude for personalized AI coaching.

  • Sessions start only at SkillPilot: A new learning session is prepared through Start learning in the shared SkillPilot web interface. The permanent SkillPilot ID remains in the SkillPilot web interface and SkillPilot Core.
  • Time-limited learning session: In the prepared start message, Claude receives only a random, opaque session identifier. After your explicit selection, SkillPilot passes this message to the input field using the sole q parameter of https://claude.ai/new; Claude does not send it automatically. The identifier is valid for exactly 24 hours from the time it is issued and cannot be extended or renewed in Claude.
  • Separate authorization: The OAuth connection authenticates only the installed plugin or connector. It contains no permanent SkillPilot ID and does not select a learning state. The connector can access learning-state data only with an additionally valid 24-hour session identifier.
  • No disclosure of the permanent ID: Claude and Anthropic never receive the permanent SkillPilot ID, a SkillPilot ID file, or its password.

3. Data transmitted to Claude

During a coaching session in Claude, the system retrieves project-related learning-state data through standardized MCP tools:

  • The current topic and learning goals of the selected curriculum
  • Daily plan status per subject: goals due today, how many are already mastered or still open, and any open backlog; plan and landscape identifiers are not transmitted to Claude
  • Learning state and mastery values (without personal clear-text identifiers)
  • Results of assessments (Verified Recall / exam evaluations)

4. Retention and revocation

The clear-text session identifier is not stored; SkillPilot stores only its provider-specific HMAC verification value. Every normal learning session expires absolutely after 24 hours. Session-bound idempotency and security records expire no later than the associated learning session. Expired records are removed regularly.

OAuth access tokens for the purely technical plugin connection are short-lived; the currently intended validity is no more than one hour. Rotating refresh tokens are currently valid for no more than 30 days. Renewing this technical connection neither extends a learning session nor establishes access to a learning state.

You can disconnect the technical connection through the OAuth revocation endpoint invoked by Claude. This invalidates the associated OAuth authorizations. The underlying SkillPilot learning state, the permanent SkillPilot ID, and connections from other providers remain unchanged.

5. Data processing by Anthropic

Anthropic's Consumer Terms of Service and Privacy Policy additionally apply to data processing within Claude, including prompts, responses, and chat history.
