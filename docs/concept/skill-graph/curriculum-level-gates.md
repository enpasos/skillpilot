# Curriculum Level Gates — Compatibility Reference

The current rule is [B9 on unit ordering (§11.5)](learning-unit-progression.md#sec-unit-progression). Atomic prerequisites determine which goals are reachable. Among those goals, `after` orders suggestions. The learner’s explicit choice and a dated learning plan take priority.

A learner may choose an available assessment in their scope while the preceding unit is still open. [Direct assessment access (§8.4)](context-and-views.en.md#sec-exams)
