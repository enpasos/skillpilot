# Curriculum Level Gates — Compatibility Reference

The active discussion is [Learning-Unit Progression and Access Policy](learning-unit-progression.md).
Its structural foundation is [Learning Units](learning-units.md), not a second
curriculum-level model.

Recursive completion and stable global recognition are defined. Whether a
whole-unit prerequisite expresses regular learning order or also blocks
technical access remains **undecided**, including its interaction with direct
assessment attempts. The earlier whole-level gate was a conditional example,
not a universal prerequisite or activated course mode.

This page preserves the old link. Use the active progression document for the
conditional gated example and its decision boundary, and
[Graph Definition §11.5](learning-unit-progression.md) for the formal contract. No new schema or runtime gate is announced.
