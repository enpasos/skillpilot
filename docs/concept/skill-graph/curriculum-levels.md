# Curriculum Levels — Compatibility Reference

The current term is **learning unit** (*Lerneinheit*). Each unit has a learning promise and can contain child units. The existing contract checks own goal obligations and required children. The proposed unit assessment would let learners demonstrate the stated learning promise with reviewed evidence bound to the unit version. [Learning units (§11)](learning-units.md#sec-unit-completion)

For the order in which units are suggested, see [B9 on unit ordering (§11.5)](learning-unit-progression.md#sec-unit-progression). For calendar dates and workload, see [Optional planning (§12)](planning-and-budget.en.md#sec-levels).
