A Gymnasium source touching Sekundarstufe I is duration-complete only when it has one of these reviewed outcomes:

1. explicit G8/G9 source evidence plus duration-specific composition views where the learner-facing tree differs;
2. a reviewed single-duration/source-policy decision that intentionally maps the source to one duration model or to a duration-neutral projection;
3. a reviewed no-difference decision showing that G8 and G9 use the same learner-facing projection for that subject and jurisdiction.
