# Former Claude beta on the shared origin {#historischer-claude-coach-beta-pfad-abgelöst}

The first Claude beta shared a server origin with other coaches. Its runbook records the rollout conditions, assessment-data checks and test procedures used for that integration. The dedicated Claude connector subsequently replaced it. For today's beta, use the [learner setup](https://skillpilot.com/plugins#claude) or the [personal marketplace release record](claude-personal-marketplace-release.md).

Current provider status is documented in the [personal Claude marketplace runbook](claude-personal-marketplace-release.md), the [neutral OpenAI cutover](openai-stable-origin.md) and the separate [Gemini integration candidate](gemini-integration.en.md). No new rollout or host acceptance is claimed here.
