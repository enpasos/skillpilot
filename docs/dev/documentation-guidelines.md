## 1. Documentation Guidelines

Every documentation file in `docs/` has one primary role so durable concepts, QA rules, generated status snapshots, and dated dossiers stay cleanly separated.

<a id="sec-dev-dg-roles"></a>
### 1.1. Document Roles and Placement Rules

| Role | Purpose | Canonical Location | Source of Truth? |
| --- | --- | --- | --- |
| **Concept** | Durable domain model, semantics, and architecture | `docs/concept/` | Yes |
| **Runbook** | Repeatable operational command steps | Near the owning process doc | Yes |
| **Process** | Review rules, status meanings, and decision gates | `docs/qa-ci/` or `docs/dev/` | Yes |
| **Generated status** | Computed report, queue, or dashboard snapshot | `docs/qa-ci/status/` | No |
| **Pilot or dossier** | Dated investigation, PoC, or one-off audit record | `docs/qa-ci/archive/` or `docs/dev/` | No (unless stated) |
| **Implementation note** | Developer-facing schema, tool, or migration detail | `docs/dev/` (`tmp/` for throwaway work) | Sometimes |

<a id="sec-dev-dg-compendia"></a>
### 1.2. Bilingual Single-Source Compendia (`docs/compendia.json`)

Durable reference handbooks are authored as bilingual (`de`/`en`) single-source compendia compiled by [`scripts/doc_compendium/`](https://github.com/enpasos/skillpilot/tree/main/scripts/doc_compendium) and [`build_compendia.py`](https://github.com/enpasos/skillpilot/blob/main/scripts/build_compendia.py) into MkDocs Web Markdown pages and typeset LuaLaTeX PDFs. Never mix languages in one file and never hand-edit generated Web pages; edit `source/chapters/*.{de,en}.md` with 1:1 AST block parity, identical `{#sec:...}` / `anchors="..."`, `@ref{sec:...}`, canonical `repo:...` links, and pure ASCII code blocks (`<= 72` chars/line). <a id="sec-dev-dg-navigation-checks"></a>
### 1.3. MkDocs `[ DE | EN ]` Switcher, Generated Notices, Templates, and Checks

- **Site navigation & `[ DE | EN ]` pill switcher:** `mkdocs.yml` (`site_url: https://enpasos.github.io/skillpilot/`) pairs `Compendium (EN)` / `Kompendium (DE)` nav groups and registers standalone pairs under `standaloneBilingualPairs` in `docs/compendia.json`. `language-switcher.js` + `bilingual-map.js` toggle active-language pages while keeping monolingual operational/dated pages visible in both modes. Unlisted dated dossiers and `docs/qa-ci/status/` reports remain reachable via section `index.md` files.
- **Generated notices & templates:** Generated Markdown files declare `Generated by`, `Regenerate with`, and `Source of truth` headers registered in [`generatedMarkdownNoticeRegistry.ts`](https://github.com/enpasos/skillpilot/blob/main/app/scripts/generatedMarkdownNoticeRegistry.ts) (`npm run check:generated-doc-notices`, `npm run check:generated-status-registry`). Durable QA lane docs follow `Purpose / Source Of Truth / Generated Artifacts / Run / Blocking Semantics / Review Ledger / Review Workflow / Expansion Criteria / Related Documents`; runbooks follow `Run The Audit / Inspect Results / Decide Or Fix An Item / Interpret Diagnostics / Verify Local Changes`; PoC/archive records carry ISO dates in filenames.
- **Terminology, outside-`docs/` links, and CI checks:** Core vocabulary follows the [Glossary](../concept/glossary.md) and [`checkTerminology.ts`](https://github.com/enpasos/skillpilot/blob/main/app/scripts/checkTerminology.ts) (`npm run check:terminology`). Links leaving `docs/` must use GitHub `https://github.com/enpasos/skillpilot/blob/main/...` (or `/tree/main/...`) URLs so published site pages never `404`, verified by `.github/workflows/docs_checks.yml`:

```bash
git diff --check
cd app
npm run check:terminology
npm run check:docs-links
npm run check:docs-indexes
```
