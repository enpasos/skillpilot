## Dokumentationsrichtlinien {#sec:dev-doc-guidelines}

Jede Dokumentationsdatei unter `docs/` besitzt genau eine primäre Rolle, damit dauerhafte Konzepte, QS-Regeln, generierte Statusberichte und datierte Dossiers sauber getrennt bleiben.

### Dokumentrollen und Ablageregeln {#sec:dev-dg-roles}

| Rolle | Zweck | Typischer Ablageort | Source of Truth? |
| --- | --- | --- | --- |
| **Konzept** | Dauerhaftes Domänenmodell, Semantik und Architektur | `docs/concept/` | Ja |
| **Runbook** | Wiederholbare operative Befehlsschritte | Nahe beim Prozessdokument | Ja |
| **Prozess** | Review-Regeln, Statusbedeutungen und Entscheidungsgates | `docs/qa-ci/` oder `docs/dev/` | Ja |
| **Generierter Status** | Berechneter Bericht, Queue oder Dashboard-Snapshot | `docs/qa-ci/status/` | Nein |
| **Pilot oder Dossier** | Datierte Untersuchung, PoC oder einmaliges Audit | `docs/qa-ci/archive/` oder `docs/dev/` | Nein (außer benannt) |
| **Implementierungsnotiz** | Entwicklerseitiges Schema-, Tool- oder Migrationsdetail | `docs/dev/` (`tmp/` für Experimente) | Teilweise |
{cols="20%,34%,28%,18%"}

### Zweisprachige Single-Source-Kompendien (`docs/compendia.json`) {#sec:dev-dg-compendia}

Dauerhafte Referenzhandbücher werden als zweisprachige (`de`/`en`) Single-Source-Kompendien gepflegt und durch [`scripts/doc_compendium/`](repo:scripts/doc_compendium) sowie [`build_compendia.py`](repo:scripts/build_compendia.py) in MkDocs-Webseiten und gesetzte LuaLaTeX-PDFs übersetzt. Sprachen werden niemals innerhalb einer Datei gemischt und generierte Webseiten nie manuell editiert; gepflegt werden ausschließlich `source/chapters/*.{de,en}.md` mit 1:1-AST-Blockparität, identischen `{#sec:...}`- / `anchors="..."`-Markern, `@ref{sec:...}`, kanonischen `repo:...`-Links und reinen ASCII-Codeblöcken (`<= 72` Zeichen/Zeile). Vertragsgepinnte Deploy-/Freeze-Dokumente, datierte Workboards und generierte Statusreports bleiben eigenständige Markdown-Dateien.

### MkDocs-`[ DE | EN ]`-Schalter, Generierungshinweise, Vorlagen und Checks {#sec:dev-dg-navigation-checks}

- **Navigation & `[ DE | EN ]`-Sprachumschalter:** `mkdocs.yml` (`site_url: https://enpasos.github.io/skillpilot/`) paart `Compendium (EN)`- / `Kompendium (DE)`-Gruppen und registriert Einzelpaare unter `standaloneBilingualPairs` in `docs/compendia.json`. `language-switcher.js` + `bilingual-map.js` schalten aktive Sprachseiten um, während einsprachige Betriebs- und Arbeitsdokumente in beiden Modi sichtbar bleiben. Datierte Dossiers und `docs/qa-ci/status/`-Berichte bleiben über die Abschnitts-`index.md` erreichbar.
- **Generierungshinweise & Vorlagen:** Generierte Markdown-Dateien führen `Generated by`-, `Regenerate with`- und `Source of truth`-Köpfe gemäß [`generatedMarkdownNoticeRegistry.ts`](repo:app/scripts/generatedMarkdownNoticeRegistry.ts) (`npm run check:generated-doc-notices`, `npm run check:generated-status-registry`). Dauerhafte QA-Lane-Dokumente folgen `Purpose / Source Of Truth / Generated Artifacts / Run / Blocking Semantics / Review Ledger / Review Workflow / Expansion Criteria / Related Documents`, Runbooks folgen `Run The Audit / Inspect Results / Decide Or Fix An Item / Interpret Diagnostics / Verify Local Changes`, und PoC-/Archivdateien tragen ISO-Daten im Dateinamen.
- **Terminologie, Links außerhalb von `docs/` und CI-Gates:** Das Kernvokabular folgt dem [Glossar](repo:docs/concept/glossary.md) und [`checkTerminology.ts`](repo:app/scripts/checkTerminology.ts) (`npm run check:terminology`). Verweise aus `docs/` auf andere Repositorypfade nutzen GitHub-URLs (`https://github.com/enpasos/skillpilot/blob/main/...` bzw. `/tree/main/...`), geprüft in `.github/workflows/docs_checks.yml`:

```bash
git diff --check
cd app
npm run check:terminology
npm run check:docs-links
npm run check:docs-indexes
```
