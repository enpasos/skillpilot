## Documentation Guidelines {#sec:dev-doc-guidelines}

Every documentation file in `docs/` has one primary role so durable concepts, QA rules, generated status snapshots, and dated dossiers stay cleanly separated.

### Document Roles and Placement Rules {#sec:dev-dg-roles}

| Role | Purpose | Canonical Location | Source of Truth? |
| --- | --- | --- | --- |
| **Concept** | Durable domain model, semantics, and architecture | `docs/concept/` | Yes |
| **Runbook** | Repeatable operational command steps | Near the owning process doc | Yes |
| **Process** | Review rules, status meanings, and decision gates | `docs/qa-ci/` or `docs/dev/` | Yes |
| **Generated status** | Computed report, queue, or dashboard snapshot | `docs/qa-ci/status/` | No |
| **Pilot or dossier** | Dated investigation, PoC, or one-off audit record | `docs/qa-ci/archive/` or `docs/dev/` | No (unless stated) |
| **Implementation note** | Developer-facing schema, tool, or migration detail | `docs/dev/` (`tmp/` for throwaway work) | Sometimes |
{cols="20%,34%,28%,18%"}

### Bilingual Single-Source Compendia (`docs/compendia.json`) {#sec:dev-dg-compendia}

Durable reference handbooks are authored as bilingual (`de`/`en`) single-source compendia compiled by [`scripts/doc_compendium/`](repo:scripts/doc_compendium) and [`build_compendia.py`](repo:scripts/build_compendia.py) into MkDocs Web Markdown pages and typeset LuaLaTeX PDFs. Never mix languages in one file and never hand-edit generated Web pages; edit `source/chapters/*.{de,en}.md` with 1:1 AST block parity, identical `{#sec:...}` / `anchors="..."`, `@ref{sec:...}`, canonical `repo:...` links, and pure ASCII code blocks (`<= 72` chars/line). Contract-pinned deployment/freeze records, dated workboards, and generated status reports remain standalone Markdown files.

### MkDocs `[ DE | EN ]` Switcher, Generated Notices, Templates, and Checks {#sec:dev-dg-navigation-checks}

- **Site navigation & `[ DE | EN ]` pill switcher:** `mkdocs.yml` (`site_url: https://enpasos.github.io/skillpilot/`) pairs `Compendium (EN)` / `Kompendium (DE)` nav groups and registers standalone pairs under `standaloneBilingualPairs` in `docs/compendia.json`. `language-switcher.js` + `bilingual-map.js` toggle active-language pages while keeping monolingual operational/dated pages visible in both modes. Unlisted dated dossiers and `docs/qa-ci/status/` reports remain reachable via section `index.md` files.
- **Generated notices & templates:** Generated Markdown files declare `Generated by`, `Regenerate with`, and `Source of truth` headers registered in [`generatedMarkdownNoticeRegistry.ts`](repo:app/scripts/generatedMarkdownNoticeRegistry.ts) (`npm run check:generated-doc-notices`, `npm run check:generated-status-registry`). Durable QA lane docs follow `Purpose / Source Of Truth / Generated Artifacts / Run / Blocking Semantics / Review Ledger / Review Workflow / Expansion Criteria / Related Documents`; runbooks follow `Run The Audit / Inspect Results / Decide Or Fix An Item / Interpret Diagnostics / Verify Local Changes`; PoC/archive records carry ISO dates in filenames.
- **Terminology, outside-`docs/` links, and CI checks:** Core vocabulary follows the [Glossary](repo:docs/concept/glossary.md) and [`checkTerminology.ts`](repo:app/scripts/checkTerminology.ts) (`npm run check:terminology`). Links leaving `docs/` must use GitHub `https://github.com/enpasos/skillpilot/blob/main/...` (or `/tree/main/...`) URLs so published site pages never `404`, verified by `.github/workflows/docs_checks.yml`:

```bash
git diff --check
cd app
npm run check:terminology
npm run check:docs-links
npm run check:docs-indexes
```
