    SkillPilot-Release für den persönlichen Claude-Marketplace

    Dieses Runbook regelt den Repository-gestützten persönlichen Marketplace für skillpilot-coach-v1. Er verteilt genau einen konkreten Claude-Plugin-Kandidaten; der Marketplace-Mechanismus selbst verändert diesen Kandidaten nicht. Es handelt sich nicht um einen von Anthropic kuratierten oder von Anthropic verifizierten Eintrag. Version 1.1.13 ist im öffentlichen persönlichen Marketplace veröffentlicht; ihr exakter Quellstand, das Paket und das Repository wurden unabhängig verifiziert. Die Website bietet derzeit das passende Archiv 1.1.13 an. Die vollständige Abnahme im echten Client steht weiterhin aus; die Repository-Veröffentlichung belegt weder eine Installation noch eine Synchronisierung in jedem Konto. Früher veröffentlichte Pakete und deren Nachweise bleiben unveränderliche Historie.

Die exakten Client-Abnahmenachweise für Web und Android Voice bleiben daher ausstehend.
