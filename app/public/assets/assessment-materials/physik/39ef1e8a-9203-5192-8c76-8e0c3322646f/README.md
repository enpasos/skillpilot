# CIE-1931-Farbangleichungsdiagramm / colour-matching plot

`cie1931-color-matching.svg` und `.png` sind eine von SkillPilot erstellte
Diagrammadaption der Daten **International Commission on Illumination (CIE)
(2019), Colour-matching functions of CIE 1931 standard colorimetric observer**,
CIE, Wien. Datensatz: [DOI 10.25039/CIE.DS.xvudnb9b](https://doi.org/10.25039/CIE.DS.xvudnb9b),
[Original-CSV](https://files.cie.co.at/Publications-datasets/CIE_xyz_1931_2deg.csv).
SHA256 der verwendeten Original-CSV:
`fa663e3535a7e0763a745993a1f0a192eb0275ac46ad2d1befd7626841e713c1`.

Die pauschale CC-BY-4.0-Lizenz für eigene SkillPilot-Inhalte ersetzt diese
separate Fremdmateriallizenz nicht.

Änderungen / changes: Aus den Tabellenwerten wurden drei beschriftete Kurven
über der Wellenlänge gezeichnet; Achsen, Legende und Layout wurden für die
Aufgabe ergänzt und als SVG und PNG exportiert. Die Kurven sind standardisierte
XYZ-Farbangleichungsfunktionen des 2°-Beobachters, keine gemessenen individuellen
Zapfenempfindlichkeiten. CIE bestätigt damit weder die Aufgabe noch SkillPilot.

Diese Dateien sind genaue Prüfungsstimuli. Inhaltliche Veränderungen erfordern
eine erneute Prüfung der zugehörigen Aufgabe; dekorative Illustrationserzeugung
ersetzt sie nicht.
