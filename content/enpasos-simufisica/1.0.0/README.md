# Physik mit SimuFísica

Das freiwillige Paket ergänzt das Lernziel „Freier Fall experimentell untersuchen“. Ein Elektromagnet gibt eine Stahlkugel frei. Zwei bewegliche Sensoren erlauben, die Durchgangszeit für verschiedene Strecken selbst zu untersuchen. Die Auswahl liefert jeweils einen Link in der Unterrichtssprache. [Deutsches Labor](https://simufisica.com/de/freier-fall/) · [English lab](https://simufisica.com/en/free-fall/)

Im Cockpit lässt sich das Paket über das Zahnrad unter **Zusätzliche Lernmaterialien** ein- und ausschalten. **Materialauswahl speichern** übernimmt die Auswahl für das persönliche Profil. Beim Lernziel „Freier Fall experimentell untersuchen“ erhalten Cockpit und Coach den passenden Link.

Beim Versuch liegt der erste Sensor unterhalb der Freigabestelle. Für den Zeitmodus beginnt die Messung bei der ersten Sensorpassage und endet bei der zweiten. Am ersten Sensor besitzt die Kugel bereits die Geschwindigkeit $v_1$. Bei nach unten positiver Achse gilt für den Sensorabstand $d=v_1\Delta t+g\Delta t^2/2$. Für einen Versuch vom Loslassen aus der Ruhe bis zum Aufprall steht die im Lernziel enthaltene Messreihe bereit.

SimuFísica stellt die Simulation bereit, enpasos kuratiert den Verweis. Die Zuordnung wurde anhand der deutsch- und englischsprachigen Anbieteranleitung am 23. November 2026 geprüft. SkillPilot verlinkt die externe Anwendung auf Wunsch. Der Coach kann das Ziel mit den bereitgestellten Messwerten vollständig im Chat bearbeiten.
