# Required assessment-material provenance repair

The unpublished package 1.3 candidate transports 28 existing task images at
31 actual task uses, alongside 836 existing learning illustrations. Original
asset bytes, public URLs, task text and learner results are unchanged.

The new provenance class binds the declared material inventory and the real,
hash-bound authored task sources. It invents neither generation prompts nor
provider provenance. All 864 embedded assets retain pending human redistribution
decisions; package publication remains blocked. This is build-candidate
conformance, not publication approval.

`receipt.actual.json` binds the actual new-ledger generation, current-ledger
check and adversarial self-test, plus the provisioner and completion 1.1
regression logs. The missing reviewed-assessments source bundle is restored
byte-for-byte from the retained authoring artifact. Its independent comparison
covers all 43 declared released tasks; the retained bundle's additional draft
is not introduced into runtime targets or granted a new content review.

The earlier helper-level negative cases are retained separately; the final
ledger self-test reconstructs provenance from current sources and also rejects
missing or stale declaration/source bindings, lost task use, fictitious prompts
and automatic redistribution approval. Full package build/consumer acceptance,
remote CI and main integration are separate evidence.
