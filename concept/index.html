    Concept Documentation Index

    This page is the entry point for durable SkillPilot concepts. Keep implementation plans and migration workboards in docs/dev/; keep CI rules and review processes in docs/qa-ci/.

    Foundations

    • Glossary · English PDF Precise definitions of core SkillPilot terms, with the normative source per term.
    • Levels of Personalization Product-level personalization model.
    • Content Integration Architecture Provider-independent optional content packages separated from the curriculum and personal selection (Issue #50).
    • Curriculum Quality: QA Maturity Levels and Human Trials Target concept for M7 as the completion of deep curriculum QA, separate Champion trial statuses, and a unified gray-green maturity scale.

    Platform Strategy

    • Portable Agent Runtime Architecture Strategy for separating SkillPilot Core, interchangeable MCP host, and interchangeable model provider, including state/privacy boundaries, billing model, staged rollout, and dated market appendix.

    Skill Graph

    • Skill Graph Overview Entry point for graph semantics, curriculum structure, and supporting contracts.
    • The SkillPilot Graph Definition (PDF) Complete typeset specification with mathematics, bilingual illustrations, and 145-rule matrix.
    • SkillPilot Skill Graph Specification (§§1–5) Core skill graph model and formal vocabulary.
    • Context, Views, Scope and Goal Types (§§6–10) Canonical skill graph vs. educational views, personal curriculum closure \(L=\mathrm{Closure}(S)\), understanding/memorisation/assessment goals, time and evidence boundaries.
    • Learning Units (§§11.1–11.4) Recursive units with a learning promise, subunits, application assessments, and derived completion; acquired competence remains globally valid.
    • Learning Unit Progression (§11.5) Explicit dependencies between whole units, valid block ordering, and the separate decision about recommended routes versus technical entry gates. The former unit-concept address and progression-concept address remain short compatibility pointers for existing links.
    • Optional Acquisition and Time Planning (§12) Multi-period acquisition plans, structural prerequisite witnesses, and workload budgets.
    • Assessment-Gated Completion and Global Mastery (§13) Direct assessment access and globally effective mastery through independent application in valid local learning-unit assessments.
    • Product Decision of 4 November 2026: Mastery via Understanding and Independent Application (DE) Binding concept clarification; implementation and review of existing assessment contracts remain separate.
    • Graph Definition Compendium Appendices (B–F) Current implementation status, verification strategy, glossary/symbols, sources, and single-source build reference.
    • Architecture & Interchange Compendium (PDF) Unified single-source compendium covering the layered goal system, node types, view projection, source/content links, visualizations, GoalBook review pipeline, canonical Gymnasium rollout, MEM/FWU roundtrip, dual curriculum package releases, and learning-unit design criteria.
    • General Goal System and Migration Long-term goal-system split and migration direction.
    • Node Types Node semantics and classification.
    • View Projection and Goal Placement Scope-specific learner-facing views and placement semantics.
    • Source and Resource Links Provenance and source/reference semantics.
    • Atomic Goal Visualizations Production pipeline and review rules for optional atomic-goal image assets.
    • Human-Readable Source Rationales Generated explanation model for tracing learning goals back to source evidence.
    • Learning-Goal Book and Evidence-Review Pipeline Versioned one-goal-per-page HTML/PDF publication and fast multi-AI evidence-review model with a separate slow public feedback channel.
    • Teacher Goal Book and Local Time Planning Scope-safe goal selection and a calendar timeline in the existing local teacher course plan, without central class storage.
    • Canonical Gymnasium Rollout Policy Conceptual rollout rules for canonical German Gymnasium subjects.
    • MEM/FWU Roundtrip Plan Concept plan for MEM/FWU graph interchange.
    • Dual Curriculum Package Releases Target architecture for equivalent JSON-runtime and FWU-ontology release packages, standalone consumption, and repository decoupling.
    • Learning-Unit Design Criteria and Examples Purpose of a unit, criteria for meaningful boundaries and assessments, two worked candidates, and the unit validity rules R1–R5 of 11 November 2026.
    • Knowledge Context What a learner can be assumed to know at a goal, derived deterministically from the graph for generation, review, and the coach. Concept, not implemented.
