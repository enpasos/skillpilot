# SkillPilot Coach 1.2.1

The coach records an eligible active goal after the required learning evidence
and, for an orientation, the learner's explicit closure. The context's
immediate actions can omit this conditional write.

The coach distinguishes a confirmed save, a pending host approval, a denied
save, a recoverable SkillPilot error and a missing response. It explains the
save status while keeping the demonstrated learning evidence in the chat.
It waits for approval when required and stops a denied write.

This draft keeps the current SkillPilot tool and authorization contract.
