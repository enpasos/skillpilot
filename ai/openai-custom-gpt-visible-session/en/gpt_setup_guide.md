# Builder Setup: SkillPilot Learning Coach – Visible Session (EN)

This configuration updates the **existing English SkillPilot GPT** in place:

`https://chatgpt.com/g/g-69a565a532008191a3b994e83d20241c-skillpilot-gpt-english`

Do not create, duplicate, or clone a GPT. Its GPT ID, URL, ownership, and sharing
stay unchanged. Do not copy any file from `ai/openai custom gpt/` into this
configuration.

## 1. Basics

- Keep the existing name, profile, and sharing configuration unchanged.
- Verify that no conversation starter invokes the old start-code flow. A regular
  launch comes from the SkillPilot Cockpit with a prepared session-token message.

## 2. Instructions

Replace the existing Instructions completely; do not append or mix them. Copy the
complete contents of `system_instructions.md` unchanged into the Builder
**Instructions** field.

Builder sanity checks:

- `getVisibleState` uses the visible `sps_...` token in the first turn.
- There is no `redeemStartCode`.
- Every ordinary answer ends in the English SkillPilot session anchor.
- Action values needed in a later turn are printed visibly first.
- The GPT never asks for a permanent SkillPilot ID.

## 3. Knowledge

First remove every legacy Knowledge file currently attached to this GPT. Then
upload only these three English files:

1. `knowledge_docs/visible_session_protocol.md`
2. `knowledge_docs/coaching_and_mastery.md`
3. `knowledge_docs/errors_and_restart.md`

Do not add legacy or German Knowledge files. In particular, no uploaded document
may direct the GPT to redeem a start code.

## 4. Action

1. Open the existing SkillPilot Action. Do not add a second Action alongside it.
2. Replace its complete schema with the package-local file
   `ai/openai-custom-gpt-visible-session/en/skillpilot-api-4ai.en.json`. Do not
   use the German file or the same-named file from the legacy package.
3. Verify that its existing authentication is still **API Key** with **Bearer**
   authentication. If Builder discarded it when the schema changed, re-enter the
   production SkillPilot Action key from deployment configuration. Never copy the
   key into a repository, Knowledge, or Instructions file.
4. If Builder requests a privacy-policy URL, use:
   `https://skillpilot.com/privacy`

This English API is fully self-contained. It must display exactly four operations
and only paths below `/api/ai/en/...`:

- `getVisibleState`
- `applyVisibleChoice`
- `setVisibleActiveGoal`
- `setVisibleMastery`

Then update/save the **existing** GPT. No new GPT URL may be created.

## 5. Capabilities

Web search and Code Interpreter are not required for this coach. Learner image
uploads may remain available for subject feedback. The coach does not render
private backend images in chat.

## 6. Acceptance test

Always test in a new chat with a fresh 24-hour token generated by the Cockpit.

1. **Startup:** Send the prepared first message. Confirm that `getVisibleState` is
   called and the exact token appears in the English session anchor as the final
   response line.
2. **Selection:** Create a state with several options. The answer must visibly show
   the selection code, numbers, and canonical UUIDs for learning goals.
3. **Follow-up turn:** Reply with a number only. Confirm that `applyVisibleChoice`
   sends exactly the visible selection code and visible number.
4. **Active goal:** Confirm that the next anchor also contains the canonical
   learning-goal ID.
5. **Teaching:** Complete at least two independent checks. Only then may
   `setVisibleMastery` run; describe it as saved only after confirmed success.
6. **Direct UUID:** Explicitly address a learning-goal UUID already visible in the
   chat and verify the direct goal change.
7. **Expiry:** Trigger `410` with an expired token. No further Actions and no stale
   session anchor may follow; the answer points to `skillpilot.com`.
8. **Negative test:** Start a chat without an `sps_...` token. The GPT must call no
   Action and must not ask for a SkillPilot ID.

## 7. Local contract validation

Run from the repository root before every Builder update:

```bash
npm test --prefix ai/openai-custom-gpt-visible-session
```
