# Builder Setup: SkillPilot Learning Coach – Visible Session (EN)

This configuration updates the **existing English SkillPilot GPT** in place:

`https://chatgpt.com/g/g-69a565a532008191a3b994e83d20241c-skillpilot-gpt-english`

Do not create, duplicate, or clone a GPT. Its GPT ID, URL, ownership, and sharing
stay unchanged. Do not copy any file from `ai/openai custom gpt/` into this
configuration.

## 1. Basics

- Keep the existing name, profile, and sharing configuration unchanged.
- Verify that no conversation starter invokes the old start-code flow. A regular
  launch comes from the SkillPilot Cockpit with a prepared session-token message.

## 2. Instructions

Replace the existing Instructions completely; do not append or mix them. Copy the
complete contents of `system_instructions.md` unchanged into the Builder
**Instructions** field.

Builder sanity checks:

- `getVisibleState` uses the visible `sps_...` token in the first turn.
- State is refreshed before every substantive ordinary follow-up turn.
- There is no `redeemStartCode`.
- Every ordinary answer ends in the English SkillPilot session anchor.
- Action values needed in a later turn are printed visibly first.
- The GPT never asks for a permanent SkillPilot ID.

## 3. Knowledge

First remove every legacy Knowledge file currently attached to this GPT. Then
upload only these seven English files:

1. `knowledge_docs/visible_session_protocol.md`
2. `knowledge_docs/state_personalization_and_progress.md`
3. `knowledge_docs/coaching_and_mastery.md`
4. `knowledge_docs/deep_linking_and_resources.md`
5. `knowledge_docs/verified_recall.md`
6. `knowledge_docs/exam_proctor.md`
7. `knowledge_docs/errors_and_restart.md`

Do not add legacy or German Knowledge files. In particular, no uploaded document
may direct the GPT to redeem a start code.

## 4. Action

1. Open the existing SkillPilot Action. Do not add a second Action alongside it.
2. Replace its complete schema with the package-local file
   `ai/openai-custom-gpt-visible-session/en/skillpilot-api-4ai.en.json`. Do not
   use the German file or the same-named file from the legacy package.
3. Verify that its existing authentication is still **API Key** with **Bearer**
   authentication. If Builder discarded it when the schema changed, re-enter the
   production SkillPilot Action key from deployment configuration. Never copy the
   key into a repository, Knowledge, or Instructions file.
4. If Builder requests a privacy-policy URL, use:
   `https://skillpilot.com/privacy`

This English API is fully self-contained. It must display exactly nine operations
and only paths below `/api/ai/en/...`:

- `getVisibleState`
- `applyVisibleChoice`
- `requestVisibleNavigation`
- `setVisibleActiveGoal`
- `setVisibleMastery`
- `startVisibleVerifiedRecall`
- `getVisibleVerifiedRecallAnswer`
- `recordVisibleVerifiedRecallResult`
- `getVisibleExamEvaluation`

All nine operations must contain `"x-openai-isConsequential": false` in the
schema source. The local package test validates this for every operation.

Builder must accept the schema without a red parameter warning. In every
operation, the `parameters` entry must directly contain
`"name": "chatSessionToken"`; it must not use a
`#/components/parameters/...` `$ref`. Seeing the nine names under “Available
actions” is not sufficient while “skipping function due to errors” still appears
above them.

Then update/save the **existing** GPT. No new GPT URL may be created.

## 5. Capabilities

Web search and Code Interpreter are not required for this coach. Learner image
uploads may remain available for subject feedback. The coach does not render
private backend images in chat.

## 6. Acceptance test

Always test in a new chat with a fresh 24-hour token generated by the Cockpit.

1. **Startup:** Send the prepared first message. Confirm that `getVisibleState` is
   called and the exact token appears in the English session anchor as the final
   response line.
2. **Selection:** Create a state with several options. The answer must visibly show
   the selection code, numbers, and full canonical IDs for learning goals;
   practice/verify copy must expose no internal action names.
3. **Follow-up turn:** Reply with a number only. Confirm that `applyVisibleChoice`
   sends exactly the visible selection code and visible number.
4. **Multi-scope:** Test an explicitly allowed multi-selection. Only then use
   `choiceNumbers`, never together with `choiceNumber`.
5. **Navigation/profile:** During coaching explicitly switch curriculum, GK/LK
   profile, learning scope, and goal. First `requestVisibleNavigation`, then visible
   choice, then `applyVisibleChoice`; an unambiguous current choice or sole option
   may be applied in the same assistant turn.
6. **Active goal:** Confirm that the next anchor also contains the canonical
   learning-goal ID.
7. **Teaching:** Complete at least two independent checks. Only then may
   `setVisibleMastery` run; describe it as saved only after confirmed success.
8. **Stable ID:** Directly address a visible stable non-UUID memory-goal ID and
   confirm that the schema accepts it.
9. **Verified Recall:** Display card IDs with prompts, load expected answers only
   after learner replies, save the whole batch before following `next`, and never
   call `setVisibleMastery` after `masterySaved=true`.
10. **Exam:** State contains no solution. `getVisibleExamEvaluation` runs only after
    complete submission. A subject-correct alternative solution in another
    representation must be graded without model-solution bias; explicitly required
    answer forms remain binding. Ask no follow-up question after submission. Save
    mastery only when the passing score is reached.
11. **Cockpit/image:** Test `interactionMode`, `requiresCockpit`, the image link,
    and state refresh after return.
12. **Progress:** Distinguish scope completion from curriculum completion.
13. **Expiry:** Trigger `410` with an expired token. No further Actions and no stale
   session anchor may follow; the answer points to `skillpilot.com`.
14. **Negative test:** Start a chat without an `sps_...` token. The GPT must call no
   Action and must not ask for a SkillPilot ID.
