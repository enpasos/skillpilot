# Deutsch: atomare Voraussetzungen und transitive Reduktion

Der lokale Datencommit `15593c82e92b62cc76601e340932800fdce8063c` baut auf [Main `62316d3`](https://github.com/enpasos/skillpilot/commit/62316d3c653c753abbb822e8e4a1f5ebd1d04fb6) auf. IDs, Texte, `contains` und alle anderen Zielfelder bleiben erhalten; Lernendenzustände und Mastery werden nicht geändert. Der unveränderte V5-Vorspann ist kanonisch an `672c5e69…` gebunden; der deduplizierte V6-Quellbestand umfasst 737 Ziele.

Drei Tests prüfen den exakt rekonstruierten V5-Vorspann: 718 Quellen werden in Laufzeitscopes erreicht, zwei weitere durch kanonische Kontrollen.
