# Retained native review inputs

These byte-preserved input trees belong to completed machine curriculum reviews.
They are retained outside `curricula/` so runtime mapping discovery cannot treat
the copied inputs as active curriculum mappings. Relative directory links at the
original review paths preserve the frozen manifests and direct input bindings.

The relocation receipts verify every retained file at both paths. Do not run old
generators against these frozen trees. New native review work belongs in `tmp/`;
publish only its explicitly bound evidence and retained inputs.

These trees contain public curriculum and review inputs, not learner, class,
session or chat data. Relocation grants no subject-matter or human approval.
